Section 4.6.3 · 中译注 + 逐式讲解

多指标与 Boosting 方法

Velu, Hardy, Nehren《Algorithmic Trading and Quantitative Strategies》· pp.152–154 · 表 4.1、式 (4.69)(4.70)

这一节是三页纸的“模型集成小百科”：先讲多个预测怎么合成一个（表 4.1 三个估计量），再讲怎么把一堆很笨的规则练成一个强规则（AdaBoost），最后落到 gradient boosting——你项目里 LGBM 的直系祖先就在这一页。

主旨一句话

单个模型永远是“某一种视角下的近似”，没有唯一正确答案；把多个视角合起来，通常比任何一个单独视角更准——而“怎么合”有两个流派：bagging 靠造多份数据降方差，boosting 靠盯住难样本降偏差。这一节把后者一路推到 gradient boosting，也就是 LightGBM 干活的方式。

零、这一节跟你项目的关系（读之前先看）

你的 LGBM 就是本节最后一段的产物 这一节的行文路线是：组合预测（表 4.1）→ 集成的两种类型（bagging / boosting）→ AdaBoost 四行算法 → 神经网络同构 (4.70) → bagging 的 bootstrap → gradient boosting。

最后这一段的描述——“前向分步地拟合加性模型，每一轮用一个弱学习器去补已有模型的短板，而短板用梯度识别；在回归场景里，这个梯度就是残差”——正是 LightGBM、XGBoost 的训练机制。你 run_research.py 里那一行 LGBM，训练的就是这个公式。

二、逐段中译

原书第 1 段 · p.152

在建立刻画数据主要特征的模型时，必须注意：模型并不唯一。因此它们会给出不同的预测。预测文献中一个众所周知的事实是：组合预测在总体上通常优于单个预测。若有 T 个模型、因而有 T 个预测 f̂1, …, f̂T，我们该如何把它们合成一个预测？由于它们都基于同一份数据，这些估计很可能是相关的，从而形成一个协方差矩阵 Σ̂f。文献中提出的三个估计量见表 4.1。

为什么“相关”这件事直接决定了合成方式 如果两个模型完全独立，它们的误差会互相抵消，平均一下就白赚一份降噪；如果两个模型完全相关（其实是同一个模型换了个写法），平均毫无意义。协方差矩阵 Σf 就是“这堆预测之间到底有多重复”的度量，所以最优权重必须由它决定——重复的少给权重，独立的（信息增量大的）多给权重。
表 4.1 · 三个组合估计量
① f̂w1 = f̂′ Σ̂f−1 f̂　　·　　② f̂w2 = f̂′ (diag Σ̂f)−1 f̂　　·　　③ f̂avg = (1/T) Σi=1T f̂i
①＝用完整协方差加权（最优但最脆弱）；②＝只保留各自方差、丢掉交叉相关（折中）；③＝简单平均（最笨但最稳）
诚实说明：书里这三个式子是“简写”，我补上标准形式 按最小化组合预测方差的标准推导，最优权重是 w ∝ Σf−11（再归一化使权重和为 1），组合预测为 f̂w = w′f̂。书里写成 f̂′Σf−1f̂，漏了归一化和全 1 向量，按字面读量纲也不对。这里按标准形式理解即可——它要表达的意思很明确：用协方差矩阵的逆来分配权重（这就是 Markowitz 组合与 GLS 的同一个数学）。
三个估计量的手算对比（两个模型，一步一步走） 第 0 步：先搞清楚 Σ 里每个数是什么。两个模型各自的误差方差：σ₁² = 4（模型 1 误差波动 ±2）、σ₂² = 9（模型 2 误差波动 ±3）；相关系数 ρ = 0.5 → 协方差 = 0.5×2×3 = 3（两者误差同向联动的程度）。拼成矩阵：
Σ = [[4, 3], [3, 9]]——对角线 = 各自准不准，非对角线 = 两个模型有多"重复"。

第 1 步：估计量的 ①（用完整协方差）。二阶矩阵求逆公式 (1/det)·[[d,−b],[−c,a]]，det = 4×9 − 3×3 = 27：
Σ⁻¹ = (1/27)·[[9, −3], [−3, 4]]。
最优权重 = Σ⁻¹ 乘全 1 向量再归一化（"全 1 向量"就是把每个模型的逆协方差行加起来——一个模型和其他所有模型的联合关系，才是它该得的权重）：
Σ⁻¹·1 = (1/27)·(9−3, −3+4) = (6/27, 1/27) → 按比例就是 (6, 1) → 归一化（6+1=7）→ w ≈ (0.857, 0.143)。

第 2 步：估计量的 ②（只看对角线，忽略相关）。直觉版"越准权重越大"：权重 ∝ 1/σ² = (1/4, 1/9) = (0.225, 0.100) → 归一化 → (0.692, 0.308)。注意到它比 ① 保守——因为它不知道"模型 1 的信息有一半模型 2 也有"。

第 3 步：估计量的 ③（简单平均）。什么都不估：(0.5, 0.5)。

读法：模型 1 精度高（方差 4 < 9）→ 三种方法都给它更多权重，方向一致；但 ① 给得最极端（0.857）——因为 ρ = 0.5 说明两个模型误差大量同向联动（信息重复），① 会把"重复的那份"从模型 2 身上扣掉、再把它独有的部分折算进去，结果权重被拉得更开。② 与 ① 的差别全部来自"知不知道相关"这一件事。
为什么是"逆" Σ⁻¹，而不是 Σ 本身？——三个层次，一个比一个深 层次一：这是解一道最优化题的结果，不是拍脑袋。
目标：让组合预测的方差最小，同时权重加总为 1。
minw Var(w′f) = w′Σw　，subject to　1′w = 1
用拉格朗日乘子 λ，一阶条件：2Σw − λ1 = 0。把这一步拆成三行，逆出现在第三行：

(a)　2Σw = λ1　　（把 −λ1 移到右边）
(b)　Σw = (λ/2)1　　（两边同除以标量 2）
(c)　Σ⁻¹Σw = Σ⁻¹·(λ/2)1　→　w = (λ/2)·Σ⁻¹1　　（两边同时左乘 Σ⁻¹，这一步才是"求逆"真正发生的地方）

注意用词：矩阵不能"移项"。标量方程里 3x = 6 可以写成 x = 6/3，本质是两边乘 1/3；矩阵方程同理，但必须左乘（矩阵乘法不交换，写成 Σ⁻¹Σ = I 才成立，右乘 Σ⁻¹ 得不到单位阵）。

为什么最后写成 ∝ 而不是 =：λ/2 是个未知标量，由约束 1′w = 1 定死，所以"w 与 Σ⁻¹1 只差一个常数倍"。用本节的数字验算：Σ⁻¹1 = (6/27, 1/27)，设 w = c·(6/27, 1/27)，代入 1′w = 1 → c·(7/27) = 1 → c = 27/7 → w = (6/7, 1/7) = (0.857, 0.143)，与前面手算一致。

所以"逆"是从"求导并令其为 0"这一步自然掉出来的，不是谁选的。求导把二次型 w′Σw 变成线性项 2Σw，要解出 w 就必须两边左乘逆——那一步就是乘逆。

层次二：逆是"换算率"，一维情形一眼看懂。
Σ 的物理意义是"给定权重，能算出方差"（正向换算）。而我们真正要的是反过来的问题："想让方差小，该给多少权重"——反向换算就要用逆。
一个模型时：Var = w²σ²，要"每单位风险换多少权重"，答案正是 w ∝ 1/σ²。"除以方差"这件事，在多维、相关的世界里就升级成"乘协方差矩阵的逆"——因为矩阵的逆就是矩阵版的"除以"。

层次三（最深）：Σ⁻¹ 的对角线 = 1/条件方差 = "扣掉别人之后你还剩多少独特信息"。
回到两个模型的数字（σ₁²=4、σ₂²=9、协方差 3）：
· (Σ⁻¹)11 = 9/27 = 0.333，而模型 1 的条件方差 = 4 − 3²/9 = 3，1/3 = 0.333 ✓
· (Σ⁻¹)22 = 4/27 = 0.148，而模型 2 的条件方差 = 9 − 3²/4 = 6.75，1/6.75 = 0.148 ✓

读法：这不只是数学巧合。Σ 的对角线告诉你模型 1 "自己"的方差是 4；但模型 2 已经提供了相关信息，所以模型 1 真正新增的方差只剩 3。Σ⁻¹ 的对角线量的正是这个"净贡献"（统计学里叫 precision，精度）。两个高度相关的模型，彼此的条件方差都会被放大 → 逆的对角线变小 → 权重被压下去。这就是"惩罚重复"在矩阵层面的实现。

最后一个漂亮的自检：若 ρ = 0（互不重复），Σ 变成对角阵，逆也是对角阵，逆乘全 1 向量再归一化 → (0.692, 0.308)，与估计量 ② 完全一致。所以 ② 就是"假装 ρ=0 的 ①"——两者不是两种思路，是同一个公式在"知不知道相关"上的取舍。
原书第 2 段 · p.152

由于对 Σf 的估计存在不确定性——尤其是在可能造成巨大估计误差的 regime 变化期间——简单平均估计量有时反而被提倡。在资产价格建模的语境下，Σf 的元素代表各方法在预测上的表现好坏。要使用上述加权估计量，我们需要持续跟踪各预测方法的表现，原则上预测较差的方法应获得较小权重。但关于其表现的时间跨度，即该用近期数据还是历史数据，仍是一个悬而未决的问题。

这一段是全节最“反直觉”也最实用的一句 理论上更聪明的权重（①），实践中常常输给最笨的平均（③）——因为 ① 要估一个 T×T 的协方差矩阵，参数个数是 T(T+1)/2，T 一多就估不准；估不准的权重会放大噪声，反而比等权更差。这就是金融里“估计误差 > 模型优势”的经典教训，和你 5.7 学的“多重检验 / 数据窥探”是同一个病根：参数越多，过拟合的机会越多。
原书第 3 段 · p.152

集成学习。如前所述，把多个预测（分类器）合成为一个，是许多决策者长期以来的目标。当在不同市场状态下各自成功的方法恰好互补时，这件事尤其重要。集成方法有两类：bagging 与 boosting，我们在此讨论。假设目标是依据当时可得的信息决定是否进场。想出一批简单规则相对容易，但要找到一条高准确率的规则就难多了。在 boosting 下，我们研究如何把这些简单规则一致地组合成一条“更强”的规则。其思路是：把注意力集中在那些用简单规则最难预测的样本上，再对这些规则取加权多数票，从而得到更强的规则。

“互补”两个字是集成的全部理由 两个模型如果总是同对同错，集成毫无价值（等于一个模型）。价值来自“你错我对”的那些时刻。放到市场上：趋势策略在单边市赚钱、均值回复策略在震荡市赚钱——它们在不同 regime 下互补，这才是集成的真实收益来源。这也解释了为什么“多模型平均”在金融里常比在图像识别里更有效：金融的 regime 切换特别频繁。
原书第 4 段 · p.152

为便于说明，假定我们要判断某资产价格会上涨还是下跌。在随机游走模型下，随机猜测的错误率是 0.5。而任何规则都应使错误率低于 0.5。我们从一个训练集开始：S = {(xi, yi), i = 1, 2, …, n}，其中 xi 是信息，yi 是一个二值变量，表示是否进场。假定有 T 条规则，ht(x) 为分类器，Dt 为训练集上的分布，其错误率为：

式 (4.69)
errD(h) = Pr(x,y)∼D[ h(x) ≠ y ]
在分布 D 下随机抽一个样本，规则 h 判错的概率。注意 D 是可变的——这正是 boosting 的机关：它改变的不是规则，而是样本的权重分布
原书第 5 段 · p.153

规则 ht 相对于 Dt 应具有错误率 errDt(ht)。boosting 算法如下：

AdaBoost 四行算法 · p.153
初始化：Dt(i) = 1/n，对所有 i
迭代：Dt+1(i) = (Dt(i) / zt) · exp[ −αt yi ht(xi) ]，
　　　其中 αt = ½ · ln[ (1 − errDt(ht)) / errDt(ht) ]，zt = 归一化常数
停止：当验证集上的误差不再改善时停止
最终规则：Sign[ Σt=1T αt ht(x) ]
四行里只有两个真正的想法：①判错的样本下次权重变大（指数更新）；②每轮规则说话的分量 αt 由它有多准决定
把 exp 那一行拆成三种情况，就彻底懂了 注意 yi ∈ {+1, −1}、ht(xi) ∈ {+1, −1}，所以乘积 yiht(xi) 只有两种可能：

· 判对 → 乘积 = +1 → 乘上 exp(−αt) < 1，权重变小
· 判错 → 乘积 = −1 → 乘上 exp(+αt) > 1，权重变大

这就是“盯住难样本”的数学实现：下轮训练时，那些总被判错的样本在损失函数里占的分量更重，弱学习器被迫去处理它们。

再看 αt 的形状：err = 0.5（和瞎猜一样）→ ln(1) = 0 → α = 0，这条规则一票也不给；err → 0 → α → ∞，几乎由它定胜负。这条曲线是“说得越准，嗓门越大”的精确版本。

图的重点不是长度，而是方向：错得多 → 柱子被抬高 → 下一轮的弱学习器不得不管它

原书第 6 段 · p.153

boosting 是有可能过拟合的；它的表现显然取决于两个决策（进 / 不进）能否依据历史数据被清晰分开。使用核方法可以改善局部可分性。同时，最优地提取特征 x（能够区分为 y 的两个选项）也很重要。由不同规则构成的集成，其主要优势在于：所有规则都犯同一个错误，是不太可能的。上述算法被称为“自适应 boosting 算法（AdaBoost）”，由 Freund 与 Schapire（1995, 1996, 1997）提出，它会自动“适应”手头的数据。如果第 t 个分类器 ht(x) 是带参数的，整体预测器取形式

式 (4.70)
h(x) = Sign[ Σt=1T αt · Sign( wt′x + bt ) ]
书里原话：这就是一个有 T 个隐藏单元的两层神经网络——boosting 与神经网络在结构上是同一种东西
(4.70) 这句话的分量：两个看似无关的流派其实是一家人 boosting（逐个加弱学习器）和神经网络（同时训练所有隐藏单元）最终都写成“一堆基函数的加权和”。差别只在训练方式：神经网络用反向传播一次性调所有参数，boosting 用贪心的前向分步一个一个加。这也解释了为什么梯度提升（下一段）能自然地推广到任意损失函数——它本质上是“用函数做梯度下降”。
原书第 7 段 · p.153

bagging 的想法来自在多份“结构应当相似”的数据集上训练规则。这些数据集通过bootstrap 重采样得到，也就是说它们不会太相似。对于资产价格数据，它们常被 AR(1) 模型表示、且系数接近 1，此时系数样本估计的渐近分布是非正态的；所以 bootstrap 样本也可用来构造合适的抽样方差。bootstrap 样本通过对新息（innovation）或经验残差重采样来生成。从单个数据集 S 出发，我们造出 M 个 bootstrap 样本 S1, …, SM，每个含 n 个样本；然后在这些样本上分别跑 boosting，再平均。正如文献所指出的，bagging 倾向于降低方差，因此可作为正则化的一种替代（Breiman, 1996）。

这里藏着一个和你直接相关的技术点 “AR(1) 系数接近 1 → 渐近分布非正态 → 所以要 bootstrap”——这句话和你在 5.7 学的块 bootstrap 是同一个道理的另一面：

· 5.7 里的块 bootstrap（block = 21）是为了对付重叠标签带来的自相关，用途是估置信区间；
· 这里的 bootstrap 是为了对付近单位根导致的非标准分布，用途是造训练集 / 估方差。

同一个工具，两种用途。而且两处的“整块重抽”理由完全相同：你的样本按天相关，抽单日会破坏相关结构。
原书第 8 段 · p.153–154（全节落点）

由 Breiman（1999）提出的梯度提升方法，以及 Friedman 等（2000）与 Friedman（2001）推广的、称为 LogitBoost 的程序，进一步改进了 AdaBoost。该方法一开始就以前向分步（forward stage-wise）的方式拟合一个加性模型（集成）Σt αtht(x)。在每一阶段，引入一个弱学习器，去弥补现有弱学习器的短板。在梯度提升中，梯度被用来识别这些短板；在回归语境下，它们就是残差。于是训练集变成 S* = {(xi, yi − h(xi)), i = 1, …, n}，把残差当作数据来对待，和 S 一样处理。优化的方式是沿着函数梯度的反方向移动。

把“拟合残差”讲成一句人话 第 1 轮模型 h1 做完预测，总会剩下没解释掉的部分：残差 = 真实值 − 已预测值。第 2 轮不去重新学整个问题，只学“第 1 轮错在哪儿”——用残差当新标签；第 3 轮学前两轮合起来还剩的残差……每一轮都在补前面所有轮次的集体短板，最后把 T 个弱模型加起来。

为什么叫“梯度”？因为“残差”恰好是平方损失对预测值的负梯度：∂/∂F (y−F)² = −2(y−F)。换成别的损失（比如分类的对数损失），负梯度就不再等于残差，但“沿负梯度方向补一步”这个动作不变——这就是 gradient boosting 比 AdaBoost 更通用的原因：它不绑定某一种损失函数。
脚注（原书 p.154） “梯度提升在开源库 XGBoost 中有现成实现。”——你用的 LightGBM 是同一族（直方图分裂 + leaf-wise 生长），机制与这段描述一致：每棵树拟合上一轮集成模型的负梯度。

三、手算：一轮权重更新，看懂 boosting 的引擎

三个样本、标签正负交替的设定，跑一轮 AdaBoost，把每一步的算术摊开。样本：x1=1（y=+1）、x2=2（y=−1）、x3=3（y=+1）。弱学习器 = 一条阈值规则：h1：x ≤ 1.5 判 +1，否则判 −1。

步骤计算结果
① 初始化D(i) = 1/n，n = 3每个样本 1/3
② 判错情况h1 对 x1 判 +1 ✓、x2 判 −1 ✓、x3 判 −1 ✗只有 x3 错
③ 加权错误率只数错的那个样本的权重：D(x3)err = 1/3
④ 规则的话语权α1 = ½·ln[(1 − 1/3) ÷ (1/3)] = ½·ln 2α1 = 0.347
⑤ 权重更新判对者 ×exp(−0.347) = 0.707；判错者 ×exp(+0.347) = 1.414未归一化 (0.236, 0.236, 0.471)
⑥ 归一化三者之和 = 0.943，逐个相除(0.25, 0.25, 0.50)
这六个数字里，只有第 ⑥ 行值得记住 判错的样本，权重从 1/3 变成 1/2（翻倍）；判对的从 1/3 降到 1/4。下一轮的弱学习器在最小化加权错误率时，为了少犯错，会优先去把 x3 弄对——"盯住难样本"不是一句文学修辞，它就是这一步算术的直接后果。

注意 α₁ 和权重更新用的是同一个 α——这一个数在算法里出场两次：第 ④ 行它当"票"（最终投票的话语权），第 ⑤ 行它当"力"（权重更新的幅度）。α 越大，票越重，同时力气也越大。

"力气大"是什么意思？看乘数的两端：判对者乘 exp(−α)、判错者乘 exp(+α)。α 越大，exp(−α) 越接近 0（判对的被压得越狠）、exp(+α) 越大（判错的被抬得越高）——权重分布被"掰"得越厉害。三个准确率不同的规则对比（判错者与判对者的乘数之比 = exp(2α)）：

规则错误率 errα判对者 ×判错者 ×判错 : 判对 = exp(2α) = (1−err)/err
1/3（本例子）0.347×0.707×1.4142 倍
0.250.549×0.577×1.7323 倍
0.101.099×0.333×3.0009 倍
0.012.298×0.100×9.95099 倍

为什么这样设计是对的？因为越准的规则，它的错误越"值钱"：一条 99% 对的规则竟然判错了某个样本，说明这个样本极可能是真正的硬骨头（连最好的规则都栽在它身上），值得下重注去攻克；而一条 60% 对的规则本来就经常错，它的误判信息量不大，轻轻调整就行。α 同时编码了"这一票多重要"和"这次改写多用力"两件事，且都与准确率挂钩——这是 AdaBoost 最精巧的设计。

一个顺手的恒等式：exp(2α) = exp[ln((1−err)/err)] = (1−err)/err——更新之后，判错样本与判对样本的权重比恰好等于这条规则的"对错赔率"。err=1/3 → 错的比对的重 2 倍；err=0.01 → 重 99 倍。规则越准，它对训练集的"改写"就越狠。

这张表解释了两件事：①为什么算法要求弱学习器必须好于 0.5——err ≥ 0.5 时 α ≤ 0，这条规则不但没用还会倒扣；②为什么 boosting 不能无限加轮次——一旦某轮在某批样本上做到 err≈0，α 会爆炸，整个模型被这一轮绑架，这就是过拟合的具体形态。

最容易搞混的一点：AdaBoost 里有两个"权重"，规律正好相反 "错误率越高 → 权重越高"这句话，对样本成立，对规则恰好相反——因为它们是两个不同的东西：

样本权重 Dt(i)规则话语权 αt
挂在谁身上挂在一个数据点上（x3 这个样本）挂在一条规则上（h₁ 这条阈值）
决定它的是这条规则判没判错它——判错的样本被抬高这条规则整体准不准——err 越低票越重
走向越难越重：1/3 → 1/2（翻倍）越准越重：err 0.4→0.25，α 从 0.20→0.55
作用在哪影响下一轮训练（弱学习器优先照顾谁）影响最终投票（Sign 里各条的票数）

为什么规则的票必须跟着准确率走、err=0.5 要归零？因为最终规则是 Sign[Σαtht]，每条规则的一票会加进同一个总和。一条 err=0.5 的规则，判断和抛硬币没区别——它的票是纯噪声，加进来只会稀释那些真有信息的规则票。给它权重不是"重视弱者"，是往池子里掺水。

样本就完全不同了：一个难样本依然含有真实信号（它只是难，不是假），所以该被抬高、被重点照顾。一个是"票"（看信息量），一个是"力"（看难度）——票按准确率分，力按难度分。

补一个细节：严格说 err > 0.5 的规则并非毫无价值——把它的输出反号就变成好规则（70% 错 → 翻过来 70% 对）。所以实现里遇到 err ≥ 0.5 的候选通常是翻转或丢弃，而 err = 0.5 是唯一"反不反都一样"的点——零信息点恰好就是瞎猜点，这也是 α 公式在此归零的深层原因。
最终规则为什么是"符号"而不是"平均" Sign[Σ αtht(x)]：每条规则投一票，票的方向是它的判断（+1 进 / −1 不进），票的重量是 αt。加起来为正就进、为负就不进。

和自己手算对不上的地方不要慌：3 个样本、2 条阈值规则的小例子里，两条规则的信息高度重复，往往凑不出"两个弱合成全对"的效果——这恰恰说明集成需要"互补"而不是"重复"（原文第 3 段那句"在不同 regime 下各自成功的方法恰好互补"）。真实数据上 T 常是几百上千轮，是否收敛交给验证集判断，这就是算法第四行的"停止时间"。
