这是技术规则的"主力部队"：三种均线（SMA / EWA / BWMA）、布林带、双均线振荡器、RSI。本节的结构是"先摆装置、再装仪表、最后给仪表一个统计学的读数"——收尾那句"所有规则都能写成收益分布 c.d.f. 的形式"，正是 §5.10（成交量进模型）和你 M 因子的方法论入口。

本节主旨（一句话）

上一节的滤波只有一个旋钮 x，本节把"工具箱"铺开：均线族负责"平滑掉噪音、留下趋势"，布林带往均线里加回波动率，双均线交叉用"两条平滑线的相对位置"代替"价格对一条线的穿越"，RSI 则直接量化"最近涨跌的力量对比"。最后原文做了最重要的一步：把每条规则都翻译成随机游走模型下收益分布 c.d.f. 的读数——规则不再是图形直觉，而是模型的检验统计量；也正因为有了模型，成交量这类新信息才有位置可以"正式加进来"。

二、逐段中译与讲解

① 开场补刀：Fama–Blume 度量对滤波有偏（p.164 顶部）

原书第 1 段 · p.164

有人指出，Fama 和 Blume 的度量在寻找成功滤波规则这件事上存在偏倚。统计量 X 和 x 是为多头策略设计的——投资者在未持仓时把资金放在无风险资产里。若定义持仓日与非持仓日累计超额收益之差为：

(5.5)
RF* = (1/N) [ Σt∈I(rt − rf) − Σt∈O(rt − rf) ]
I = 持仓日集合，O = 空仓日集合。注意分母是 N（全部天数），且空仓日的超额带负号进入。

则可证 E(RF* − RBH) = (1−2f)PR − PR = −2f·PR——是常数风险溢价的一个固定比例，因此造成偏倚。

这个 bias 在数学上是怎么发生的（手算） 在"无本事世界"里每一天期望超额都是 PR。RF* 的两个舱：
· 持仓舱：(1−f)·N 天 × PR = (1−f)N·PR
· 空仓舱：**负号** × f·N 天 × PR = −fN·PR（空仓日你没赚到的超额被记成了"损失"）
合计 E(RF*) = (1−2f)·N·PR/N = (1−2f)PR。而 RBH = PR，相减：
E(RF* − RBH) = (1−2f)PR − PR = −2f·PR < 0（只要 f>0）

代数字：PR = 0.5%/天时，f=0.1 → 偏置 −0.10%/天；f=0.3 → −0.30%/天。哪怕滤波毫无本事也被判负——但注意方向：这个 bias 是不利于滤波的，所以 Fama–Blume 那句死刑判决其实"偏严不偏松"。真正的含义是：上一节 (5.2) 用 (1−f)·RBH 校正暴露是必要的，若用 (5.5) 这种口径直接比，结论会失真。同一份成绩，口径选错，正负结论都能造出来——这就是"口径"这一课的第二集（第一集是 5.2 的 x vs X）。

② 三种均线（p.164）

原书第 2 段 · p.164

均线交易规则通常基于当前价格与过去价格某种移动平均的比较。考虑价格 Pt, Pt−1, …, Pt−m+1，窗口宽度 m。文献中有多种均线，其相对优劣取决于价格形态：

(5.6)
SMA: P̄(m)t = (1/m) Σi=0m−1 Pt−i
EWA: P̄(m)t = [1/Σi=0m−1λi+1] · Σi=0m−1 λi+1 Pt−i
BWMA: P̂(m)t = [1/Σi=1mi] · Σi=0m−1 (m−i)·Pt−i
平滑常数 λ 必须在 0 与 1 之间。SMA 等权；EWA 按指数衰减加权（越新越重）；BWMA 按线性递减加权（第新的权 m，第旧的权 1）。

基于这类指标的规则在呈现明确趋势的市场中往往有盈利，因此它们一般被称为"趋势跟随"（trend-following）指标，有时也称"动量"指标。

三种均线手算对比（同一窗口 m=5，价格 [100, 102, 101, 105, 104]，λ=0.9）：

均线权重（旧→新）结果
SMA每个 1/5 = 0.200102.400
EWA0.160 → 0.178 → 0.198 → 0.220 → 0.244（指数衰减，最新权最大）102.168
BWMA1/15 → 2/15 → 3/15 → 4/15 → 5/15（线性递增）101.667

注意排序：BWMA < EWA < SMA。窗口里最新的 104 是偏低的价，谁的"新价权"越大，就被拉得越低——三种均线本质是同一窗口上三种"记忆衰减曲线"，它们没有绝对好坏，只有"对最近的反应快慢"之分。

"记忆"差多少？改一个数试试 把最后一天 104 改成 120（大涨），其余不动：
· SMA：102.40 → 105.60，动了 3.20（每个价都均摊 1/5，新价进来大家重新洗牌）
· EWA：102.17 → 104.73，动了 2.56——慢着，EWA 权最新价最重，怎么反而动得少？
因为 EWA 的权重是归一化后 0.244 对比 SMA 的 0.200？不对——真相是：EWA 版本里旧价的权合计仍占 75.6%，而新价在旧价群体中"稀释"得更多；同时 λ=0.9 衰减慢、新旧差不大。真正决定"反应速度"的不是加权形式本身，而是有效窗口宽度（EWA 的半衰期 ≈ ln2/ln(1/λ) ≈ 6.6 天，比 m=5 还长）。λ 小 → 记忆短 → 反应快但噪音多；λ 大 → 记忆长 → 平滑但滞后。这条和你调 LGBM 超参是同一种权衡：响应度 vs 稳定度。

③ 交易规则与两种哲学：反转 vs 动量（p.164）

原书第 3 段 · p.164

实践中的一些简单规则：

规则
SMA 规则：若 P̄(m)t/Pt > U 或 < L，则交易
EWA 规则：若 P̄(m)t(λ)/Pt > U 或 < L，则交易
U、L 是上下阈值（如 1.02 与 0.98）。"交易"的方向见下一段。

两类潜在策略大致称为"反转"（Reversal）与"动量"（Momentum），区别主要在进场的时点：逆向者（contrarian / 反转）寻找局部最低点进场；动量追随者寻找局部最高点进场。

同一条均线，能装出两种截然相反的策略 比率 P̄/P 本身只告诉你"价格在均线上方还是下方"，不告诉你该买还是该卖——方向是策略设计者选的：

· 动量派：P 上穿均线 → 趋势启动 → 买（追涨）；P 下穿 → 卖。
· 反转派：P 跌破均线过深（比率 < L）→ 超跌 → 买（抄底）；上冲过高 → 卖。

所以"用均线"这个说法本身没有信息量，"用均线 + 选边"才有。这两派不可能同时正确——市场若趋势性强，动量对；若均值回归强，反转对。这不是哲学之争，是关于收益自相关符号的实证问题——正是 ⑥ 段随机游走解读要回答的（γ(h) 的符号决定谁有理）。

④ 布林带：把波动率加回均线（p.165）

原书第 4 段 · p.165

上述规则容易实现，但没有考虑价格（收益）过程的方差或波动率。广泛使用的布林带（Bollinger band）在概念上类似于监控制造业质量过程，它基于加权均线和方差。定义标准差：

定义
σ̂t = { (1/(m−1)) Σi=0m−1 (Pt−i − P̄(m)t)² }1/2
BWMA 规则
若 Pt > P+ = P̂(m)t + 2σ̂t（上带），则卖出；
若 Pt < P− = P̂(m)t − 2σ̂t（下带），则买入；
两者之间不行动。

大体上，移动平均、加权平均等关键量对应 Lai 与 Xing (2008) 讨论的滑动均值平滑器。有些技术规则不用滑动均值，而用滑动最大值 / 最小值（max / min0≤i≤m Pt−i），这些规则的性质同样容易研究。

布林带手算（接上面 m=5 窗口：均值 102.400，样本标准差 σ̂ = 2.074）：

量算式值
中轨P̄ = 102.400102.40
上带102.400 + 2×2.074106.55
下带102.400 − 2×2.07498.25

价格在 [98.25, 106.55] 之间时什么都不做——带子外的世界才触发交易。与滤波对比：滤波的门槛是"固定的百分比 x"，布林带的门槛是"相对当前波动率的 2 个标准差"——市场安静时带子自动收窄（灵敏），市场狂躁时带子自动放宽（钝感）。这就是"考虑了方差"的含义。

注意：书里这条布林带规则是"反转式"的——和网上流行版本相反 原文写得很清楚：碰上带卖出、碰下带买入（超买卖超卖买，均值回归逻辑）。而坊间流行的布林带突破策略是"突破上带追涨买入"（动量逻辑）。两种用法在文献里都存在，但本节的写法是反转式——和 ⑤ 段 RSI 的"超买/超卖"家族同门。别把两版混为一谈，回测时方向写反等于白测。"制造业质量监控"的类比也印证反转式：指标偏离控制带 = 过程异常 = 大概率回归。

⑤ 两个振荡器：双均线交叉与 RSI（p.165）

均线振荡器 · p.165

所谓均线振荡器规则需要计算短、长两个时间跨度的均线。设 P̄(m)t 与 P̄(n)t 为短、长均线，m < n。当短均线穿越长均线时发出趋势突破信号：短均线自下而上穿过长均线发出上升趋势信号；反之自上而下为下降突破。精确地：

振荡器规则
进场：P̄(m)t−1 < P̄(n)t−1 且 P̄(m)t > P̄(n)t
离场：P̄(m)t−1 > P̄(n)t−1 且 P̄(m)t < P̄(n)t
民间叫法：金叉（进场）/ 死叉（离场）。注意条件里是两天：昨天的相对位置 + 今天的相对位置，"穿越"是一个两天事件。

金叉手算（短 m=3，长 n=5，价格先跌后涨：110→109→107→106→105→104→103→104→106→108→110→112）：

t价格短均线(3)长均线(5)信号
5104105.00106.20短<长
6103104.00105.00短<长
7104103.67104.40短<长
8106104.33104.40短<长（只差 0.07）
9108106.00105.00金叉 → 进场（昨天 104.33<104.40，今天 106>105）
10110108.00106.20短>长（持仓）
11112110.00108.00短>长（持仓）

看 t=8→9 那一步：价格 106→108 只涨了两块，短均线却从 104.33 跳到 106.00（它对新材料敏感），长均线只从 104.40 爬到 105.00（它拖着 4 天旧价）。交叉信号的本质 = 短记忆追上长记忆的那一刻。也看得到代价：t=8 只差 0.07 没触发，迟一天进场的成本是 106−104 = 2 块——平滑的滞后费。

RSI 振荡器 · p.165–166

另一个振荡器用于衡量价格朝某一方向运动的强度：相对强弱指标（RSI）。其逻辑是：若价格变化朝一个方向过快，反向修正很可能随之而来且不久出现。因此这类规则被称为"反转"或"超买/超卖"指标。定义：

原料
Ut = Σi=1m I(Pt−i − Pt−i−1 > 0)·|Pt−i − Pt−i−1|
Dt = Σi=1m I(Pt−i − Pt−i−1 < 0)·|Pt−i − Pt−i−1|
U = 最近 m 个变动里上涨部分之和，D = 下跌部分绝对值之和——把涨跌两股力量分别归拢。原文 D 舱写作 S，应为笔误。
(5.7)
RSt = Ut / Dt，　RSIt = 100 · Ut/(Ut+Dt) = 100 − 100/(1 + RSt)
RS 是"涨跌力量之比"——一个赔率比（odds ratio）；RSI 把它压到 0–100 区间。由构造，RSI 天然归一化。
反转规则 · p.166
若 RSIt > 70：超买，预示向下修正 → 离场或做空
若 RSIt < 30：超卖，预示向上修正 → 进场

RSI 手算（m=5 个变动：+2, +1, −3, +2, +1）：

量算式值

D（跌的和）33

交叉验证100 − 100/(1+2)66.67 ✓（两种写法恒等）

本例 RS=2 → RSI=66.67，还没到 70 的超买线。看懂了这对数，"RSI=70 ⟺ RS=2.33"就只是一个比例换算：

⑥ 统计地基：把规则写成 c.d.f.（p.166）

这一段的一句话主旨

把"RSI > 70 就叫超买"这句经验口诀，翻译成一句模型语言：「模型认为未来 n 天上涨的概率已经超过 70%」。翻译完，规则就不再是图形直觉，而是一个概率陈述——概率陈述能被检验、能被加条件、能算出它值多少钱。原文用三行公式完成这次翻译，跨度很大；下面拆成五级台阶，每级只用上一级的结果。

读图：分布的中心是漂移 μ，宽度是 σ′ = σ/√n。问"涨的概率"= 问 0 右边那块面积有多大。μ 只要离开 0 有 0.52 个 σ′，"超买"（RSI=70）就到了。

台阶 0：先把 Φ 当成一台"面积查询机"

Φ(z) = 标准正态曲线下、z 左边那块面积，输出一个 0–1 之间的数。它没有简单公式，只能查表（或一行代码），所以先把它当成机器，别当成神秘符号。

zΦ(z)这台机器在说什么
−1.960.025只有 2.5% 的概率比它更小——你 5.7 学的 95% 区间端点
−1.000.159左边 15.9%
−0.5240.300左边 30%（对称点）
00.500正中间，一半一半
+0.5240.700左边 70%——RSI=70 的那个点
+1.000.841左边 84.1%

唯一的对称关系要记住：Φ(−z) = 1 − Φ(z)。左右两块面积加起来恒等于 1。

台阶 1：(5.8) 说"每天收益 = 漂移 + 噪音"

原式 pt = μ + pt−1 + at，把 pt−1 移到左边就是收益：

rt = pt − pt−1 = μ + at，　at ~ N(0, σ²)

  • μ = 漂移：每天固定往上爬的一小步，方向恒定（可正可负），是"趋势"的数学化身；
  • at = 噪音：每天重新抽一次的随机抖动，均值 0、标准差 σ，是"波动"的数学化身。

代数字（σ = 1%/天、μ = 0.05%/天）：今天收益 = 0.05% + 一次抽签（多数落在 ±1% 内）。
这一级的全部意义：技术规则赌的从来不是 a（噪音不可预测），而是 μ 会不会在某些时候变大、变负。均线穿越、RSI 超买超卖，本质上都在猜 μ 的当前值。

台阶 2：取 n 天平均，噪音缩成 σ/√n，漂移不变

r̄n = (1/n)(r1 + … + rn) = μ + (1/n)(a1 + … + an)。逐项看：

成分n 个相加再除以 n 之后结果（σ=1%，n=5）
漂移 μn 个 μ 平均，还是 μ0.05%（没变）
噪音 an 个独立抖动平均，标准差 = σ/√n = σ′1%/√5 = 0.447%（缩小）

这一级是整段的技术支点：平均让噪音变小、却丝毫不改变漂移。所以"过去 5 天平均涨了"比"今天涨了"更能说明 μ 的方向——这正是均线（(5.6)）存在的统计学理由，也是 5.7 里"信号按 n 长、运气按 √n 长"的同一个 √n。

若收益有自相关，方差要换成 (1/n)Σ|h|<n(1−|h|/n)γ(h)——就是 5.7 那个自相关膨胀因子的有限样本版，连 (1−|h|/n) 的折扣都一样。下面为了看清主干，按无自相关处理（原文也是这么假设的）。

台阶 3：把"涨的概率"变成"查一次面积"

有了台阶 2，就有 r̄n ~ N(μ, σ′²)。要算的只有一件事：P(r̄n > 0) = ? 标准化（减均值、除标准差）后 z ~ N(0,1)：

P(r̄n > 0) = P( z > −μ/σ′ ) = 1 − Φ(−μ/σ′) ＝ Φ(μ/σ′)

卡住你的很可能就是这一步：两个写法为什么相等？ 因为对称关系 Φ(−z) = 1 − Φ(z)。把 z = μ/σ′ 代进去：1 − Φ(−μ/σ′) = 1 − [1 − Φ(μ/σ′)] = Φ(μ/σ′)。
原文写左边那版（1−Φ），是因为它从"r̄n > 0 等价于 an > −μ"推过来，尾概率天然长这样；而右边那版（Φ）读起来更直白："0 左边那块面积 = 跌的概率"，所以涨的概率 = Φ(μ/σ′)。两版数字完全一样：Φ(0.524)=0.700，1−Φ(−0.524)=1−0.300=0.700。

代数字：μ = 0.05%、σ′ = 0.447% → μ/σ′ = 0.112 → P(涨) = Φ(0.112) = 0.545。

直觉读法：0 这条线离分布中心只有 0.112 个 σ′ 远（几乎压在中心上），所以 0 右边面积略多于一半——涨的概率 54.5%，和抛硬币差不太多。这就是"漂移太小时，任何振荡器都测不出东西"的数学表达。

台阶 4：赔率 = 两块面积相除；而 RSI 恰好就是"涨面积 × 100"

涨面积 0.545、跌面积 0.455 → 赔率 = 0.545 / 0.455 = 1.195。

再回头看 RSI 的定义：RSI = 100·U/(U+D)，其中 U = 平均涨幅、D = 平均跌幅。现在把模型里那个式子拆成三格，和定义式逐格对齐：

RSI 定义式里的模型里换成凭什么能换
U：上涨力量(1−Φ) = P(涨)幅度相同时，"力量"正比于"涨了几次"
D：下跌力量Φ = P(跌)同理，正比于"跌了几次"
U+D：力量总和(1−Φ)+Φ = 1涨与跌互斥且穷尽，占比加总必然为 1
所以分母到底是什么：不是"除以 1"，是"除以所有类之和" "占比"的定义就是 我这一类 ÷ 所有类之和。RSI 的分母 U+D 是"涨的力量 + 跌的力量"；模型只是把"力量"换成了"次数"，于是分母变成"涨的次数 + 跌的次数"。因为只有涨、跌两类，这个和恰好等于 1——所以它数学上等于 1−Φ，但书上坚持写成 (1−Φ)+Φ，是为了让你一眼看出它就是 U/(U+D)。那个 1 是"归一化"算出来的结果，不是额外假设。
顺便回答"为什么分子是 1−Φ 而不是 Φ"：这里 Φ 指的是跌的概率（0 左边那块面积），涨是它的补集，所以分子取 1−Φ。台阶 3 里的 Φ(μ/σ′) 是涨概率——同一个字母两个含义，这种简写（原书和我上一版都这么写）极易看混，下面给符号统一版。
符号统一版（建议按这版记） 令 Φ ≡ Φ(−μ/σ′) = P(跌)，则 P(涨) = 1 − Φ = Φ(μ/σ′)。于是
RSI = 100 × (1−Φ)/[(1−Φ)+Φ] = 100 × Φ(μ/σ′)　　（Φ(0.524) = 0.700 → RSI = 70）
RSI 在模型里就是"上涨概率 × 100" 这不是巧合：RSI 被设计成"涨跌力量的占比"（0–100），而模型里的"涨的概率"天然就是一个占比。所以 RSI ≈ 100 × P(r̄n > 0)——RSI=70 的意思是"模型说涨的概率 70%"，RSI=50 是"五五开"，RSI=30 是"涨的概率 30%"。
这也解释了 RSI 为什么长在 0–100 之间、为什么 50 是天然中轴：它就是一块被放大 100 倍的面积。

台阶 4·附：这个等号有前提——RSI 是"幅度比"，模型是"次数比"

Wilder 的原始定义里，U、D 是幅度：U = 过去 n 天所有涨幅之和 ÷ n，D = 所有跌幅之和 ÷ n。而模型换成了次数。两者相等只在一种情形下成立——每个涨日和每个跌日的幅度都一模一样。

情形（都是 6 涨 4 跌）真实 RSI（幅度比）次数比对得上吗
每次涨 1%、每次跌 1%60.060.0对得上
每次涨 2%、每次跌 1%75.060.0差 15 个点

所以 "RSI ≈ 100 × P(涨)"是那条等幅二值随机游走假设的产物，不是 RSI 的普适性质。真实行情涨跌幅度不等，RSI 会系统性偏离"涨的概率"：涨得猛、跌得浅时 RSI 高于涨的次数占比，反之低于。这也顺带解释了为什么同一个"70"在不同波动环境下含义不同——它测的是"最近涨得有多凶"，不是"涨了几天"。

对你项目的用处：RSI、乖离率这类是幅度加权的位置度量，你的切割因子（cut）是次数/占比加权的量价度量。两者对同一段行情读法不同，所以"RSI 与切割因子相关性"本身就是一条值得跑的正交性检查——若相关性很高，说明你的因子在偷偷度量幅度而不是次数，那 −0.082 的符号可能来自波动而非结构。

台阶 5：反解 70——"超买线"其实是"漂移门槛"

把 RSI=70 一步步倒推回去：

RSI = 70 ⟺ P(涨) = 0.70 ⟺ Φ(μ/σ′) = 0.70
⟺ μ/σ′ = Φ−1(0.70) = 0.524

用人话读："超买"的严格含义是——最近 n 天的隐含漂移，达到了均值标准误的 0.52 倍。反算成日常单位（σ′ = 0.447%）：

μ = 0.524 × 0.447% ≈ 0.234%/天　（≈ 月 5%，年化 50%+）

所以 RSI 打到 70，等于模型在说："这只股票最近 5 天在按年化 50% 的速度往上爬"。这句话是可以被证伪的——只要拿真实数据比一比"RSI=70 之后 n 天实际上涨的频率是不是 70%"，就知道这条阈值在这只股票、这个市场上灵不灵。这就是"c.d.f. 化"给规则带来的第一份好处：从"看图说话"变成"可检验的命题"。

整张表只有一条逻辑：漂移相对于标准误越大 → 涨的面积越大 → 赔率越大 → RSI 越高。70/30 不是谁拍脑袋定的，它是"漂移 = 0.52 个标准误"这个统计事实的一个别名。

为什么值得费这么大劲：c.d.f. 化的三个用处 ① 统一尺子。滤波的 x%、均线的 U/L、RSI 的 70/30，三种完全不同的阈值，翻译成 c.d.f. 后都变成同一句话："尾概率小于多少"。不同规则第一次可以放在同一把尺子上比。
② 可以检验。规则成立 ⟺ 赔率显著大于 1 ⟺ 漂移显著不为 0。这一步直接接上你 5.7 学的 t 检验与置信区间："RSI=70 之后真的涨"这句话，可以算出一个区间，而不是靠回测的累计收益说话。
③ 可以加变量。既然规则 = 条件分布的一个尾概率，那把成交量放进条件里，规则立刻升级成 P(r̄n > 0 | 成交量)——这就是下一段"枢纽句"的全部内容，也是 §5.10 与你的 M 因子能进入模型的方法论接口。
枢纽句（全书对你的项目最重要的一句话之一） "本节陈述的所有规则都可以写成标的收益分布 c.d.f. 的形式。这种基于模型的规则解读，能帮助我们把成交量等因子更正式地纳入模型，并评估它们对策略表现的增值。"

拆开读：① 规则 = 统计量的阈值判断（RSI 是 RS 的单调变换，RS 是正态 c.d.f. 的函数）；② 既然规则背后是模型，模型里就能加变量——把成交量写进条件分布，规则就从"价格规则"升级为"量价规则"；③ "评估增值"= 比较加与不加的分布差异。这恰恰是 §5.10（Llorente 交互项、成交笔数、订单不平衡）的立项书，也是你把研报 M 因子（量价切割）放进 LGBM 而不是手工规则的方法论许可。原文还指出：技术规则在外汇市场的有效性证据最充分（Menkhoff & Taylor 2007）。
