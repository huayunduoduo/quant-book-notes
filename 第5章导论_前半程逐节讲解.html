二、逐节讲解

§5.1 出身与历史（p.159）

三大类策略的谱系。跑赢市场的尝试古已有之——原文追溯到日本投机商本间宗久（Munehisa Homma）在大米市场用"蜡烛图"形态发财，以及道氏理论"市场在某些阶段可预测"的主张。现代分类是三分法：

  • 动量策略：买入表现好的、卖出表现差的（Jegadeesh–Titman 1993）；
  • 反转策略：买过去的输家、卖过去的赢家；
  • 价值策略：买入价值股、卖出成长股（Lakonishok et al. 1994），用 PE、分红、B/M、现金流、销售增长当价值指标。

统计套利的正式定义（Hogan, Jarrow, Teo & Warachka 2004）——"产生无风险利润的长周期交易机会"，四个条件：①自融资、初始成本为零；②极限下期望折现利润为正；③亏损概率收敛到零；④时间平均方差收敛到零。它的价值在于：拒绝市场有效不依赖任何均衡模型——直接检验"策略是否构成统计套利"即可。

全章立场声明：开发策略的公共难题是交易成本（直接佣金 + 进出场间接成本）、防过拟合的交叉验证、换市场环境不保业绩；"没有任何单一策略一直有效，所以要养一篮子策略"。这一句是理解全章布局的钥匙——后面每节就是在往篮子里放一种工具。

§5.2 评价口径（pp.160–161）——已有专页

衔接说明 CAPM 回归 (5.1) 长出超额收益 / 夏普 / 特雷诺 / 信息比率 / 索提诺 / 卡玛六个比率与回测报告清单（盈亏笔数、最大单笔盈亏、净滑点、佣金、权益曲线）。逐比率讲解、DR ≠ 最大回撤辨析、比率分歧的数值验证，见学习门户中的 §5.2 策略评价口径 专页。这里只需记住它在全章的角色：它是给后面所有策略准备度量衡的，放在最前面。

§5.3 交易规则总论（pp.161–162）

技术分析（Chartist analysis）= 从价格与量的过去形态做归纳预测。原文开篇引 Menkhoff–Taylor (2007) 的困惑：按最弱形式的市场有效假说，过去的信息应该已经反映在现价里，技术分析"要么无利可图，要么利润伴随着不可接受的风险暴露"——但它在实践中（尤其外汇市场）被广泛使用。原文给的调和是：基本面能解释长期，但没有任何基本面模型能预测短期——短期预测这块地，技术分析去占。

技术分析成立的两个前提：①价格运动有某种规律性、可复现的形态；②这些形态必须持续得足够久，撑得过交易成本和假信号，投资才能变成利润。然后是全章引用率最高的一句判决（Fama–Blume 1966）：

"在漂移为零或为正的随机游走市场里，任何机械规则用于单个证券，都不会持续跑赢简单地买入持有。"

过去的走势有用，当且仅当相继价格变化之间存在某种依赖——注意原文补刀：序列相关这种度量未必能捕捉到复杂的依赖结构（这句话为 §5.5 的非线性分解、§5.4 的核方法、乃至你的 LGBM 留了口子）。

§5.3.1 滤波规则（pp.162–164）

规则本体（Alexander 1961, 1964）：从某低点上涨至少 x% → 买入持有；从随后的高点下跌至少 x% → 卖出并做空；做空后从某低点又涨 x% → 回补转多。小于 x% 的移动一律忽略。背后的逻辑是"涨了 x% 的东西，更可能先涨满下一个 x% 而不是先跌 x%"——直接赌随机游走不成立。

实证判决的三部曲（原文讲得很完整）：

研究结论
Alexander (1961)，标普工业指数日频5%、6%、8% 滤波的毛利润跑赢买入持有——但没算交易成本
后续研究加上每往返 2% 佣金只有约 46% 的大滤波勉强跑赢，其余全部不比买入持有好
Fama–Blume (1966)，道指 30 只股逐只、1957–1962"算上佣金，滤波技术的大利润属于经纪人；不算佣金，回报确实大幅改善，但仍不及买入持有"

随机游走下的模型化：rt = ln Pt − ln Pt−1 = μt + at，at~N(0,σ²)。滤波规则赌的是：入场时刻 t₀ 之后漂移 μt 从 0 变成正数 μ。若漂移真的持续，规则赚；所以滤波规则的本质是"入场时点对漂移变化的检测器"，退出规则（rt < r 就走）负责截断亏损。原文还提醒 Mandelbrot (1963) 的批评：价格在成交瞬间是跳跃的，买价卖价不会像规则要求的那样精确衔接——这是滑点的理论前身。

式 (5.2)、(5.3)：Sweeney (1988) 的风险调整检验
x = RF − (1−f)·RBH　　X = RIF − RBH
f = 未持仓天数占比。直觉：过滤器有 (1−f) 的时间躲在无风险资产里，本来就该少赚风险溢价，所以公平的比较是"滤波单位持仓天数收益" vs "扣除该份溢价后的买入持有"。在原假设（E(x)=0）下有精确的均值方差，可以做检验。式 (5.4) 把它推广到时变风险溢价，(5.5) 指出 Fama–Blume 原统计量的一个系统性偏差（对成功滤波规则不利）。

§5.3.2 均线变体与振荡器（pp.164–166）

三种均线（式 5.6 前后）：简单均线 SMA（等权）、指数加权 EWA（λi+1 衰减加权）、Bollinger 加权 BWMA（按 (m−i) 线性递减）。通用规则形态：比值 P̂(m)t/Pt 突破上界 U 或跌破下界 L 就交易。原文点明这类指标只在有明确趋势的市场里赚，所以叫"趋势跟随"（trend-following）指标。

反转 vs 动量的分界：两者规则形式相同，差别只在入场时点——反转派找局部极小值进场，动量派找局部极大值进场。

布林带：P̂(m)t ± 2σ̂(m)t，破上带卖、破下带买，带内不动——概念上就是制造业的"过程质量控制图"搬进金融。

RSI 的概率化解读（对你最有启发的一段）：RSI > 70 超买、< 30 超卖这种"拍脑袋"阈值，原文用随机游走模型反解——r̄n 的分布在自协方差全为零时退化为正态，于是"上涨概率 vs 下跌概率"的赔率比 = [1−Φ(−μ/σ)] / Φ(−μ/σ)，而 RSI > 70 恰好对应赔率比 > 2.33。原文的结论是全章的枢纽句：

枢纽句（原文 p.166） "本节所述的所有规则都可以写成收益底层分布的 c.d.f. 形式。这种基于模型的规则解读，可以帮助我们把成交量等其他因子更正式地纳入模型，并评估它们对策略业绩的增值。"——这扇门走进去就是 §5.10（量价信号），也就是你的 M 因子地盘：原文自己承认，"规则 → 概率模型 → 加新变量"是技术分析的正规化路径，你的 cut() 家族正走在这条路上。

§5.4 模式识别：核回归（pp.166–168）

问题：看图识形态（头肩顶、双底……）几十年来的致命伤是"解读全凭主观"（"often in the eyes of the beholder"）。Lo–Mamaysky–Wang (LMW, 2000) 的方案：用非参数核回归把形态识别自动化。

四步流水线：

  • 模型 (5.9)：Pt = m(xt) + at——价格 = 光滑信号 + 噪声，m 任意；
  • 估计 (5.11)：Nadaraya–Watson 核估计 m̂h(x) = ΣKh(x−xt)Pt / ΣKh(x−xt)——K 取标准正态密度，离 x 近的价格权重大、远的权重小；
  • 带宽 h：太小磨不平、太平滑丢细节，用交叉验证 (5.12)(5.13) 选——逐个把 Pt 拿出估计集、看拟合误差；LMW 发现价格序列上最优 h 偏大，建议打 0.3 折；
  • 形态匹配 (5.14)：在滑动窗口内估核回归，用 m̂ 的导数变号找局部极值，按几何性质定义十种形态。

检验与判决：用 KS 检验比较"形态出现条件下的收益分布"与"无条件分布"——结论是核回归略好于随机。Jegadeesh (2000) 的讨论击中要害：图表派相信"历史形态会重演"，但形态判定本身主观性极强；实践者的真实用法是把视觉形态与宏观事件等大信息组合起来择时。

§5.5 分解算法（pp.168–170）

动机：前面规则都是趋势跟随，而收益的可预测性按有效市场理论本来就该弱——但原文指出：收益的"方向"和"波动"的时间依赖性比收益本身强得多。Anatolyev–Gospodinov (2010) 据此把收益拆开：

式 (5.15)：恒等分解
rt = c + |rt − c| · sgn(rt − c) = c + |rt − c| · (2·I(rt > c) − 1)
c 由使用者定：可以是 σ 的倍数、交易成本、无风险利率或任何基准。收益 = 基准 + 幅度 × 方向。方向用 Bernoulli/logit (5.19) 建模（协变量可含已实现方差 RV、双幂变差 BPV、已实现偏度峰度），幅度用 ACD 型 Weibull (5.17)(5.18) 建模（可含宏观预测变量），两者用 copula (5.20) 缝合成联合分布。

为什么值得拆：(5.16) 显示条件期望 Et−1(rt) 可以写成 RVt−1 的非线性函数（含 RV² 项）——分解天然容纳非线性。即使价格真是随机游走、收益是白噪声，这个框架也能捕捉部分时间依赖。策略用法：预测超额收益为正就投股票、为负就投债券，实证上分解法略优。

神经网络亲戚 (5.21)–(5.23)：AR(p) 加入振荡器信号 sm,nt（短长均线之差）→ 扩展线性模型 → 前馈神经网络（logistic 激活）。Gencay (1998) 用 1877–1998 道指日频数据证明振荡器信号里存在非线性可预测性。你的 LGBM 在概念上就是这件事的现代版：不直接猜收益，让模型自己从特征里找可预测结构。

§5.6 公允价值模型（p.170）

这一节是你 E2 residualize() 的直系祖先 逻辑：股票的"公允价格"由共同因子驱动（CAPM、Fama–French 三/五因子、Carhart）。用因子模型拟合后，因子解释不掉的大偏离 = 异常 = 交易机会。这就是"公允价值"得名的原因：它给策略业绩提供了"合理基准"。具体到 (5.1)：模型成立则 α=0，α≠0 就是风险调整后的超额业绩；(5.24) 把 α 写成均值与 β 的函数；(5.25) 承认高频下残差有序列依赖 εt = at − φat−1（MA(1)），估计用迭代广义最小二乘；泛化为多因子 (5.26)：rt = α + β′ft + εt。

对照你的项目：preprocess.py::residualize()（同日横截面岭回归取残差）就是这个思想在横截面上的实现——剥掉市场/风格共性，看每只股票剩下什么。E2 的设计哲学与本节一字不差。

§5.7 回测与数据窥探（pp.171–174）——已有专页 ×2

衔接说明 §5.3–5.6 收集了满满一篮子规则，§5.7 建立法庭：White Reality Check (5.27)–(5.31)、逐步 SPA (5.32)、FDR 视角；Sullivan 等人 7846 条规则的判决——Brock 等经典均线规则的显著业绩是数据窥探的伪结果，1987–2000 年间"不进场"的日子平均收益反而更高。逐公式拆解与手算见 §5.7 中译注 与 5.7 公式精讲（小白版）。注意 Bajgrowicz–Scaillet (2012) 的收尾句很诚实："我们的结果对其他市场、其他频率、更复杂的规则说得很少"——这句也是给你的负结果留的后门。

§5.8 配对交易（pp.174–184）

思想：市场中性策略——找价格同涨同跌的一对相似证券，价差显著偏离时做多低估的、做空高估的，等错定价自我修正时获利。价差幅度 = 错定价程度 = 潜在利润空间。因为利润与基本面变化无关，这类交易有时被称为"噪声交易"；配对策略反过来还能用来度量噪声交易者风险。

教科书案例：孪生股。Royal Dutch/Shell 合并前按 60:40 分红，理论平价比 = 0.6×Shell 股数 ÷ 0.4×Royal Dutch 股数；Unilever NV/PLC 有"一股 NV = 1.67 股 PLC"的平价协议——实际价差对理论平价的偏离曾高达 27%（1999 年 2 月）。Froot–Dabora (1999) 的补充发现很深刻：股价运动跟随的不是基本面而是交易发生地的市场。自然孪生股难找，实践中用"同行业、长久期、宏观暴露相似"的成熟公司凑对。

距离法算法（Gatev–Goetzmann–Rouwenhorst 2006）：

  • 每月末，用过去 12 个月累计收益指数把每只股票价格归一化；
  • 对每对股票计算归一化价差序列的均值 d 与标准差；
  • 价差偏离超过 2 个标准差 → 买便宜的卖贵的；收敛即平仓；六个月不收敛强制平仓。

Gatev 等用 1962–2002 日频数据发现配对交易在各大类行业都有利润，且超额收益不能被市场/SMB/HML/动量/反转因子解释——"配对交易与简单的反转策略根本不同，尽管概念上长得一样"。

协整版本（§5.8.2）：若价格向量 pt 协整（秩 r），则存在 r 个线性组合是弱依赖的——偏离这个线性组合的部分是暂态的、会回归。写成协整 VAR 让"配对"推广到"一篮子"，参数也有了统计推断的框架。§5.8.3–5.8.4 讨论样本外表现衰减与执行细节（含与做市策略耦合的玩法，原文 p.184 有一段精彩描述）。
