零基础操作指南

新数据获取：每一步该做什么

这份手册把原来那份技术文档重排了一遍。每格只做一件事，做完打勾。每格最后都写了「怎么算成功」和「卡住了怎么办」，不用理解原理也能往下走。

0先看清你现在缺什么

整件事的前提是：有一台装了 Wind 终端、并且已经登录的 Windows 电脑，上面放着那个带 research 文件夹的项目包。我检查了你这台电脑，情况是这样：

要的东西状态说明
conda 环境 qlib_beginner有Python 3.12.15，已装 pyqlib 0.9.7
项目文件夹（含 research 目录）没有全盘搜索未找到，这是当前最大障碍
Wind 终端没有本机未安装 Wind
WindPy 库（Python 读 Wind 的接口）没有环境里没有
run_wind_first_check.ps1 一键脚本没有属于那个项目包，跟着包一起缺
所以现在不要敲任何命令 手册里的每条命令都依赖那个项目包。没有它，你只会看到 No module named 'research' 这类报错，然后误以为是自己操作错了。先完成第 1 步，再谈后面。

1把项目包找出来

回忆一下这个项目包你是怎么拿到的 —— 微信/邮件收到的压缩包？还是别人给你的远程桌面？找到它所在的电脑，然后判断属于下面哪种情况：

  • 情况 A：你自己的电脑装了 Wind → 直接在这台机器上做，最省事。
  • 情况 B：公司/学校有一台 Wind 电脑，你用远程桌面连过去 → 必须把整个项目文件夹复制到那台远程电脑上，不能只在自己这边打开 Windows 窗口。这是原手册特别强调的一点，很多人在这里搞错。
  • 情况 C：你没有 Wind，只是想先看看 → 那这件事今天做不了。先联系给你这份材料的人，问清楚 Wind 账号和项目包。
怎么算成功 你能明确说出「我要在 ___ 这台电脑上操作」，并且那台电脑上能找到项目文件夹。
卡住怎么办 如果是压缩包还没解压：右键 → 全部解压，别在压缩包里直接运行。解压后路径里不要有中文和空格，比如放 D:\qlib_beginner 就好，别放「D:\我的项目\新建文件夹 (2)」。

双击进入项目文件夹，你应该能看到（名字可能略有差异，但大意一致）：

research\ ← 最关键 configs\ data\ run_wind_first_check.ps1 requirements-news.txt WIND_SUPPORT_REQUEST.txt
怎么算成功 能看到 research 这个文件夹，点进去有 .py 结尾的文件。只要有它，后面的命令才跑得动。
卡住怎么办 如果只有 site-packages\qlib 而没有 research，说明你找错地方了 —— 那是 Python 装库的目录，不是项目。回到第 1 步重新找。原手册也专门提醒过这个坑。

2打开命令行，站到项目文件夹里

最简单的办法：在资源管理器里进入项目文件夹 → 点一下上方地址栏 → 把路径整个删掉，输入 powershell → 回车。会弹出一个蓝色/黑色的命令行窗口。

另一个办法：在文件夹空白处 Shift + 右键 → 「在此处打开 PowerShell 窗口」。

怎么算成功 窗口里最前面显示的路径，和你的项目文件夹路径一致。比如 PS D:\qlib_beginner>。
卡住怎么办 如果路径显示的是 C:\Users\你的名字>，说明没进对地方。补一条命令：cd D:\qlib_beginner（换成你自己的实际路径），再回车。

在刚才的窗口里粘贴这一行，回车：

conda activate qlib_beginner
怎么算成功 命令行最前面会多出一对括号，变成 (qlib_beginner) PS D:\qlib_beginner>。看到括号就对了。
卡住怎么办 提示「conda 不是内部或外部命令」→ 说明这台电脑没装 conda 或者没配好。但你的本机是装了的（C:\Users\30600\miniconda3），所以更可能是在另一台机器上没装。装个 Miniconda 即可，或者问给你材料的人。

3跑第一个命令，只生成代码清单

这一步只是把「哪些股票要研究」列成一张清单，不碰 Wind、不消耗配额、不下载行情。适合当第一个测试。

python -m research.export_wind_codes

跑完会多出两个文件：

  • configs\wind_codes_historical_csi300.txt —— 历史上沪深300成分股的代码并集，加上基准 000300.SH
  • data\wind_acquisition\code_list_receipt.json —— 记录这份清单的来源
怎么算成功 没报错，并且 configs 文件夹里真的出现了那个 .txt 文件。用记事本打开能看到一堆类似 600000.SH 的代码。
卡住怎么办 No module named 'research' → 你不在项目文件夹里，回第 2 步。
No module named 'pandas' 之类 → 环境没激活，回第 2 步检查有没有那个括号。

4一键体检（懒人版，推荐）

如果项目里有 run_wind_first_check.ps1，直接跑它，它会依次做四件事：生成代码清单 → 探测行情字段 → 下载 5 只股票样例 → 探测新闻接口。不会启动全量下载，可以放心跑。

.\run_wind_first_check.ps1
怎么算成功 屏幕上依次出现四个环节的输出，最后 data\wind_acquisition\ 和 data\news_raw\ 里多出若干 json/csv 文件。
卡住怎么办 提示「无法加载文件……未对文件进行数字签名 / 禁止运行脚本」→ 这是 Windows 的执行策略限制。用这行临时绕过，只对当前窗口生效，不改系统设置：
powershell -ExecutionPolicy Bypass -File .\run_wind_first_check.ps1 不想折腾就直接跳过这步，手动一条条跑第 3、5、6 步。

5探测「成交笔数」到底叫什么

Wind 里每个数据项都有个英文代号，比如成交额是 amt、成交量是 volume，而「成交笔数」可能是 dealnum —— 但不同账号权限不同，不能想当然。这条命令会让脚本拿一只股票、一个月的数据去挨个试探候选字段：

python -m research.data_acquisition_wizard --mode probe --code 600000.SH --start 2025-01-01 --end 2025-01-31

这一步必须在 Wind 已登录的电脑上跑，否则一定失败。跑完会生成 4 个文件，全在 data\wind_acquisition\ 里：

  • field_probe.csv —— 每个候选字段的错误码、有多少行不是空值、样例值
  • field_map_suggestions.json —— 试成功了的字段
  • probe_values.csv —— 探测区间里的真实数值样例
  • probe_summary.json —— 汇总小结
怎么算成功 4 个文件都生成了。field_probe.csv 里能看到有字段的非空数量大于 0。
卡住怎么办 全部字段都失败 → 大概率是 Wind 没登录、或者账号没这个数据权限。
不要自己瞎猜字段名，也不要用 amount/volume 去冒充成交笔数 —— 那算出来的是成交均价，不是平均单笔金额，结论会完全错。
这一步为什么重要（一句话版） 整个研究要靠「平均每笔成交多少钱」这个指标。它必须用 成交额 ÷ 成交笔数 算。拿不到笔数，这个指标就是假的 —— 所以不能跳过核验。

6下 5 只股票试试水

探测没问题后，下 5 只股票一年半的数据看看。注意结尾的 --limit 5，它保证只下 5 只：

python -m research.data_acquisition_wizard --mode download --codes configs/wind_codes_historical_csi300.txt --start 2024-01-01 --end 2025-05-30 --limit 5

默认写到 data\wind_sample\，不会碰正式的 data\wind_raw\。用 Excel 打开 CSV，检查两件事：有没有 amount 和 trade_count 这两列；日期范围对不对、有没有大片空白。

怎么算成功 data\wind_sample\ 里出现 5 个 CSV，打开能看到日期、开盘、收盘、成交额、成交笔数等列，数值看着合理。
卡住怎么办 如果最基础的 open/high/low/close/volume/amount 都没通过，脚本会自动停下 —— 这是保护机制，别去改代码硬闯。
如果只有 trade_count 失败，脚本会继续下行情，但会明确警告「不能复现理想反转因子」。看到这个警告，说明这个研究做不完整。

7新闻部分：现在先别碰

新闻这条路比行情复杂得多（要处理标题、正文、发布时间、防「未来信息泄漏」、还要跑情绪模型）。原手册里 C 之后那一大段（导出、规范化、情绪打分、日频因子）现在完全不用看。今天只做这一条：

python -m research.wind_news_probe --code 600000.SH --start 2025-01-01 --end 2025-01-31

跑完看 data\news_raw\wind_news_api_probe.json 里两个值：

  • method_available 和 query_succeeded 都是 true → 好消息，后面可以继续做
  • 有一个是 false → 不代表你没买新闻数据，可能只是你这个 WindPy 版本或账号没开这个接口。别自己猜接口名，把那个 json 发出去问
卡住怎么办 项目里有现成的 WIND_SUPPORT_REQUEST.txt，是写好的中文话术，直接复制发给 Wind 客户经理，问清四件事：有没有 A 股历史新闻 API、字段有哪些、能回溯到哪一年、调用额度多少。
一个必须知道的事 如果你只能从 Wind 界面手工点「导出」，导出的是「当前最新新闻」，不能拿来做 2010–2025 的历史回测。想要全历史，必须走 API，手工点几百只股票不现实。

8把 4 个小文件发给我

先别全量下载。只要把这 4 个文件发过来，就能判断下一步怎么走：

  • data\wind_acquisition\field_probe.csv
  • data\wind_acquisition\probe_summary.json
  • data\wind_acquisition\probe_values.csv
  • data\news_raw\wind_news_api_probe.json
绝对不要发的 Wind 登录密码、授权令牌、整个商业数据库原始文件。上面这 4 个文件本身不含密码，是安全的。

✓术语对照：看不懂的词查这里

Wind 终端
万得（Wind）是金融数据软件，国内机构几乎都用。它只能装在指定电脑上，而且要账号登录才能用。
WindPy
让 Python 能读取 Wind 数据的那个「转接头」库。没装它，Python 拿不到数据。
字段 / 字段名
数据项的名称。比如「收盘价」这个数据项，在 Wind 里的代号是 close。「成交笔数」的代号是 dealnum（待核验）。
dealnum
候选的「成交笔数」字段。一定要验证单位——是笔还是手，算错会让整个因子失真。
conda / 环境
可以理解成「一间独立的工具房」。qlib_beginner 这间房装了 qlib 等工具，别的房间没有。所以要先 conda activate 进去。
PowerShell
Windows 自带的命令行窗口，用来敲命令的地方。不是黑客工具，就是个高级输入框。
远程桌面 / RDP
在自己电脑上看到一个别人电脑的窗口，能操作它。关键点：操作的是那台电脑，不是你的。所以文件得复制过去。
API
程序之间的取数通道。有 API 就能批量自动拿数据；没 API 就只能手工点界面导出，做不了历史回测。
配额
Wind 给你的取数次数上限。全量下载会消耗很多，所以要先小样本测试，别一上来就拉十年数据。
冒烟测试
行业黑话，意思是「先跑个最小的样本，看会不会炸」。就是先下 5 只股票的意思。
PIT / 防泄漏
Point-in-Time，指「当时真的能拿到的信息」。比如某条新闻 3 月 5 日晚 8 点才发布，就不能假装在 3 月 5 日收盘前已经知道它——否则回测收益是假的。
CG / 代码生成器
Wind 终端里的一个小工具，能查某个字段的中文含义、单位、有没有权限。
-m research.xxx
意思是「运行 research 文件夹里的某个脚本」。所以人必须站在项目文件夹里，否则找不到。

!小白最容易踩的 6 个坑

  • 坑 1：在自己电脑上敲远程电脑的命令。远程桌面里敲命令，命令跑在远程那台；你在本地 PowerShell 敲，跑在本地，两边环境完全不同。
  • 坑 2：项目文件夹没复制到远程电脑。原手册专门强调：整个 qlib_beginner 文件夹都要复制过去，包括 research。只复制一部分没用。
  • 坑 3：用今天的沪深300成分股回测过去。这会造成「幸存者偏差」，结论虚高。手册用的是历史成分区间，别图省事换成当前名单。
  • 坑 4：拿成交额 ÷ 成交量当「平均单笔金额」。那是成交均价，单位完全不同。这两个指标长得像，含义天差地别。
  • 坑 5：一上来就全量下载十年数据。配额烧完了才发现字段是错的。永远先 5 只股票试。
  • 坑 6：新闻接口没通就说「新闻因子提升了收益」。手册里写得很清楚：必须先做 Alpha158-only / News-only / 两者结合的三组对照，在同一套滚动样本和成本假设下比较，才能下结论。没做对照之前，这句话不能写进任何材料。
最后一句实话 这份材料的技术含量不低，但它的核心难点不在敲命令，而在数据权限——你有没有 Wind 账号、账号有没有 dealnum 和新闻 API 的权限。这两件事定死了，后面全是机械操作。所以今天你只需要搞定第 1 步和第 8 步，中间的可以等拿到权限再说。
