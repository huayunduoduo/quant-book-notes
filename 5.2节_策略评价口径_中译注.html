Section 5.2 · 中译注 + 逐条讲解

策略评价：各种测度

Velu, Hardy, Nehren《Algorithmic Trading and Quantitative Strategies》· pp.160–161 · 公式 (5.1) 及六个比率

这一节非常短（只有 1.5 页），但它是全书其余部分的度量衡：后面每个策略的表现，都要用这里定义的尺子来量。对你来说，它是把 5.7 的"统计检验"补成"完整回测报告"的那块拼图。

主旨一句话

评价一个策略不能只看"赚了多少"，要看扣除风险、扣除基准之后还剩多少。这一节从一条回归式 (5.1) 长出四个比率（α、夏普、特雷诺、信息比率），再补两个盯住亏损的比率（索提诺、卡玛），最后给一份标准回测报告清单。

零、先摆清楚你自己的东西（读译文之前必看）

你现在的评价体系缺了一整层 你目前所有结论都产自 5.7 的口径：RankIC + 配对增量 + 块 bootstrap 置信区间（E1 −0.001297 [−0.006907, +0.003756]；E2 −0.000251 [−0.001474, +0.000592]）。

这套口径量的是"信号质量"——信号和未来收益的横截面相关有没有增量。

但这一节的口径量的是"组合业绩"——真按这个信号买卖（你的月度 top50 等权），账户的收益、波动、回撤长什么样。这是两层不同的度量，论文和答辩两样都要有：
层级量什么你的现状本节补给你
信号层RankIC、配对增量 CI、多重检验校正✓ 已完整（5.7 口径）—
组合层α、夏普、索提诺、卡玛、回撤、换手、滑点✗ 基本空白：top50 等权组合只有收益，没有成体系的报告一整套比率 + 一份标准报告清单
这一节的文章逻辑：一条回归式长出一家人 这一节只有 1.5 页，结构极简单，就三步：

第 1 步：给一条"标准归因方程"——CAPM 回归 (5.1)。把你的策略收益拆成三块：市场给你的（β·市场）、真正属于策略的（α）、剩下的噪声（ε）。
第 2 步：四个比率 = 用方程里不同的零件做分子、不同的风险做分母。它们不是四条独立知识，是同一个拆解的四种读法。
第 3 步：再补两个盯住"亏损那一侧"的比率（索提诺、卡玛）+ 一份标准报告清单。

读的时候每遇到一个比率，就问一句：它的分子是哪块、分母在罚什么。这一节就通了。

逐段中译（pp.160–161）

① 开篇：这些尺子和执行策略的尺子不是一套（p.160）

原书第 1 段

本节要梳理的是交易策略一般如何被评价。这些测度不同于评价执行策略所用的测度——后者将在第四部分讨论。这里关注的是业界通行的基准，它们提供了当策略失灵时需要逐一检查的一组维度。

"策略失灵时需要逐一检查的一组维度"——这句是本节的纲 每个比率都是一个独立的"体检指标"：夏普差可能是波动大，α 差可能是选股弱，卡玛差可能是一次深回撤拖垮的。一个策略可以夏普合格但卡玛很难看——只报一个数字就发现不了。这就是为什么要有"一组"而不是"一个"。

② 一切的起点：CAPM 回归（公式 5.1）

原书第 2 段

标准测度源自资本资产定价模型（CAPM）：

公式 (5.1)
rt − rf = α + β ( rmt − rf ) + εt
rt 资产（策略）收益　·　rf 无风险收益　·　rmt 市场收益
斜率 β 度量资产的风险（跟随市场波动多少）　·　α 表示超额收益（市场给不了、纯靠策略本事的部分）
手算一遍：α 到底在算什么 设你的 top50 组合某年周收益均值 0.30%，同期市场周超额收益均值 0.22%，回归得 β = 0.9，rf ≈ 0.008%/周。

直观读法：市场那周平均涨 0.22% + 无风险 0.008%，β=0.9 意味着"跟着市场你该赚 0.9 × 0.228% ≈ 0.205%"，而你实际平均赚 0.30%。多出来的 ≈0.095%/周，就是你策略的 α。

为什么要先减市场？因为牛市里傻子都赚钱——不把"市场普涨"那部分剥离，你分不清策略是真有本事还是只是坐在了上升的电梯里。

③ 前四个比率：同一条回归的四种读法（p.160）

原书第 2 段（续）

令 r̄ 与 s 为评价期内收益的样本均值与标准差（分别替代下述各式中的 E(rt) 与 σ）。

超额收益（Excess Return）
α
正值代表表现更好，因为它反映的是风险调整后的收益
夏普比率（Sharpe Ratio）
E( rt ) − rf　÷　σ
用资产自身的波动率标准化。这是使用最广的基准测度
特雷诺比率（Treynor Ratio）
E( rt ) − rf　÷　β
夏普的替代版：把分母从"总波动 σ"换成"市场风险 β"
信息比率（Information Ratio）
α　÷　σ( εt )
超额收益的修正版：用残差波动标准化——每承担一份"独立于市场的风险"，换回多少 α
四个比率一起手算：同一组数字，四种读法 设某策略：E(r) = 10%，rf = 2%，σ = 20%，β = 0.8，σ(ε) = 10%，α = 3%。

比率算式结果它在问什么
夏普(10% − 2%) ÷ 20%0.40每承担 1 份总波动，换回多少超额？
特雷诺(10% − 2%) ÷ 0.80.10每承担 1 份市场风险，换回多少超额？
信息比率3% ÷ 10%0.30每承担 1 份独立风险，换回多少 α？
超额收益 α回归截距3%剥掉市场之后，你还剩多少？
注意各比率什么时候会有分歧（下面数字是构造出来验证方向的，不是原文内容）：

情形一：夏普相同，收益来源不同。A、B 超额收益同为 10%、总波动同为 20%（夏普同为 0.5）。A 的收益全来自市场暴露（β=1.2、σ(ε)≈0、α≈0），B 的收益全来自选股（β=0.2、σ(ε)≈0.20、α=10%）。算出来：特雷诺 A=0.083、B=0.500 → 特雷诺偏爱 B——因为特雷诺的分母只看 β、完全看不见 ε，β 越小它给的分数越高，所以它会系统性高估"β 小但独立风险大"的组合。信息比率也偏爱 B（A 的 α≈0 → IR≈0；B 的 IR≈0.51）——但 IR 偏爱 B 是"对的"：它量的正是选股能力本身。

情形二：特雷诺和信息比率真正的分歧。两个策略 α 相同（都 2%），但 P 是 β=1.0、σ(ε)=0.10，Q 是 β=0.5、σ(ε)=0.40。特雷诺：P=0.020、Q=0.040 → 偏爱 Q（β 小）；信息比率：P=0.20、Q=0.05 → 偏爱 P（ε 小）。分歧的根源：特雷诺用 β 当分母，信息比率用 σ(ε) 当分母——谁的风险更"便宜"，取决于你的组合观。

比率的选择本身就是一种观点表态。夏普把总波动全算你的账 → 隐含"这是你的全部仓位的钱"；特雷诺只罚市场风险 → 隐含"这只是你充分分散组合里的一小块，独立风险已被分散掉"；信息比率只认 α → 隐含"我要买的是你的本事，别的都不算"。三个隐含假设对应三种出资场景，没有谁绝对正确。
信息比率和你 E2 的 residualize() 是一家人 你 preprocess.py 里的 residualize() 做的是：同日横截面上把收益对常见因子回归、取残差。这本质上就是 (5.1) 的横截面版——把市场/风格暴露剥掉，只留策略自己的那部分。

所以 E2（residual 后的因子）天然就是"信息比率视角"下的检验：它在问"剥掉市场暴露之后，你的切割信号还剩多少预测力"。而 E1（raw）更像"夏普视角"：不剥，直接量。

E1 测不出、E2 也测不出，合起来恰好是"夏普视角和信息视角都没有增量"——这个并置可以直接写进论文。

④ 换一套视角：盯住亏损那侧的两个比率（p.160–161）

原书第 2 段（续）

上述比率着眼于投资的长期视角；业界另有两个比率，聚焦于策略的执行/亏损方面：

索提诺比率（Sortino Ratio）
E( rt ) − rtarget　÷　DR( rt )
rtarget = 投资者自选的目标利率（可以取 rf、市场平均收益、或竞争者的收益）
DR(rt) = 下行波动率（只统计低于目标的那部分波动）
卡玛比率（Calmar Ratio）
年化复合收益率　÷　最大回撤
对回撤的重视很重要，因为简单回测选出的策略没有任何未来有效的保证
辨析：DR（下行波动）不是最大回撤——三个"下行量"各管一摊 这两个词都带"亏损"味，最容易混。它们有三个根本区别：

下行波动 DR（索提诺的分母）最大回撤 MDD（卡玛的分母）
吃进去的是什么逐期收益率（每月/每日一个数），只挑低于 rtarget 的那些权益曲线（累计净值），找"从历史最高点跌到谷底"最深的那一段
数学性质一个离散度统计量（就是把 σ 改成只算亏损侧），用到所有亏损期一个极值（最惨的一次事件），只关心最深那一次，其余深浅不管
对路径的敏感度与路径无关：把收益顺序打乱，DR 不变与路径强相关：同样的收益换个顺序（亏损连在一起 vs 之间夹着反弹），MDD 完全不同

手算验证"打乱顺序 DR 不变、MDD 大变"（rtarget=0，两策略用的都是同一组月收益 {+5%, −2%, +5%, −2%, +5%}，只是顺序不同）：
· 顺序 A（亏损分散）：净值 1.05 → 1.03 → 1.08 → 1.06 → 1.11，每次只从高点回落 2%，MDD ≈ 2.0%
· 顺序 B（亏损连着来）：净值 1.05 → 1.10 → 1.16 → 1.13 → 1.11，从 1.16 一路跌到 1.11，MDD ≈ 4.0%
· 而 DR 两者完全相同 ≈ 1.26%（= √[(0.02²+0.02²)/5]，只看亏损期）

还有一个容易顺手混进来的第三个量——单期最大亏损（回测报告清单里"最大单笔盈亏"那个）：它也只取一个极值，但作用在单期收益上、不看累计净值。一句话总结：DR 管"平均每次亏多疼"，MDD 管"最惨的一次多惨"，单期最大亏损管"单月最多亏过多少"——分别喂给索提诺、卡玛和盈亏统计。
原书第 3 段

后两个比率共同结合了最大化收益（分子）与最小化损失（分母）两个想法。回撤数字本质上由交易者根据自己的经验与风险承受力确定。也有一些研究聚焦于这些准则的统计性质（见 Bertrand 与 Protopopescu（2010）关于信息比率、Lo（2002）关于夏普比率）。

为什么"只罚下行"是个大改进：手算对比 夏普的分母 σ 把上涨和下跌一视同仁。但想想这两个策略，目标利率 2%：

策略 A策略 B
收益序列+5%, +5%, +5%, −3%（均值 3.0%）+8%, −6%, +8%, +2%（均值 3.0%）
总波动 σ≈ 3.6%≈ 6.4%
下行波动 DR≈ 1.8%（只有一个 −3%）≈ 3.0%（一个 −6%）
夏普（σ 罚上涨）0.280.16 —— 被自己的好日子拖累了名次
索提诺（只罚下跌）0.560.33
两者的排序一致，但差距被放大了。极端例子：一个"每月稳赚 +2%"的策略，σ≈0，夏普趋于无穷——夏普对"稳定向上"其实给不出有意义的区分，索提诺的框架更贴近投资者真实的痛感：亏钱才难受，赚钱不难受。
卡玛比率手算：一个数字暴露"策略是赚出来的还是赌出来的" 设两个策略年化复合收益都是 12%：

· 策略 A 最大回撤 8% → 卡玛 = 12 ÷ 8 = 1.5
· 策略 B 最大回撤 40% → 卡玛 = 12 ÷ 40 = 0.3

收益完全一样，但 B 要忍受"账户一度缩水四成"才能拿到。卡玛把这种痛苦量化成一个数。书里那句"回撤数字由交易者根据自己的经验与风险承受力确定"是在提醒：分母取多大没有客观标准，这本身是主观参数。
Lo (2002)：你的年化夏普大概率被高估了 原书提到"Lo (2002) 研究夏普比率的统计性质"——这正是你在 5.7 已经撞见过的问题的业绩版：

日频 Sharpe 年化的标准做法是 ×√252，它假设日收益无自相关。但你的标签是 20 日重叠窗口——重叠自带自相关（5.7 里块 bootstrap 就是在为此付账）。自相关为正时，√252 年化高估真实夏普。

Lo (2002) 的修正式：SR年化 = SR日 × √[ 252 ÷ ( 1 + 2Σρk ) ]，ρk 是收益的 k 阶自相关。和 5.7 的 (σ²/n)(1+2Σρk) 是同一个膨胀因子。

落到项目：如果论文要报组合的年化夏普，要么先算收益的 ρk 做修正，要么用块 bootstrap 给夏普也配一个置信区间——别报一个点估计裸奔。

⑤ 标准回测报告还该有这些（p.161）

原书第 4 段

另一种测度是直接把策略收益与买入持有（buy and hold）的收益作比较。在上述测度之外，回测结果的标准报告还应包括：盈利与亏损交易的笔数、最大单笔盈利与亏损、净滑点、总佣金，以及以上各比率的年化版本。所谓权益曲线（equity curve）——即累计收益图，并与买入持有曲线并排画出——可以清晰地展示策略的有效性。

"和谁比"这个问题，你有三个天然候选 原书说基准"can be rf or the average market return or return of the competitors"。对你的项目：

· rf：货币基金收益——最低底线；
· 市场：沪深 300 指数——"不选股"的对照组；
· 竞争者：你的 E0 就是自己的"竞争者"——"不切割的信号 + 同样的 top50 规则"。

第三条最有意思：你的实验设计里其实已经内置了书中说的全部三类基准。论文里报组合业绩时，权益曲线应该画三条：E0 组合、E1 组合、沪深 300——一眼看出"切割"值多少钱。

一个诚实的提醒：这节的所有比率都能被 5.7 的教训打穿 6 个比率全是从同一段历史算出来的点估计——没有置信区间、没有多重检验校正。回测里挑出卡玛最高的那组参数，和 5.7 里"三条策略里挑最好那条"是同一个数据窥探陷阱，只是换了个马甲。

所以正确的组合拳是：这一节负责"报什么"，5.7 负责"报得算不算数"。论文里每个比率旁边最好带一个块 bootstrap 区间——这是你相对一般研报的最大方法论优势。
