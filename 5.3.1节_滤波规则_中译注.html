Algorithmic Trading and Quantitative Strategies · Ch.5

§5.3.1 滤波规则
Filter Rules（x% Filter）

原文 pp.162–163（约 2 页）· 公式 (5.2)–(5.4) · 页索引 178–179（pypdf）

这是全书第一条正式登场的机械交易规则——也是最老的一条（Alexander 1961）。本节只做三件事：① 把"涨过 x% 就买、跌过 x% 就卖"写成精确规则；② 复述它的两次历史判决（先胜后败）；③ 给出怎么公平地审判一条规则的统计工具（Sweeney 风险调整统计量）。规则本身死了，但审判工具活到了今天——它就是 §5.7 那套回测方法论的前身。

本节主旨（一句话）

滤波规则用"忽略小波动、只追大波动"来捕捉趋势，Alexander (1961) 的原始回测毛利漂亮，但 Fama–Blume (1966) 加上佣金后宣判："算上佣金，滤波技术的大利润属于经纪人"——本节的真正遗产不是这条规则，而是 Sweeney (1988) 的风险调整检验：评判一条"经常空仓"的规则，必须把它和同等风险暴露的基准比，而不是和满仓的买入持有直接比。

二、逐段中译与讲解

① 开场：什么叫做"有用的预测"（p.162 顶部）

原书 p.162 · 承接 §5.3 总论

要让技术分析有用，价格运动应当遵循某种规律的、反复出现的模式，且这些模式必须持续足够长的时期，足以覆盖交易成本和假信号，从而让投资最终盈利。从投资者角度看，"有用的预测"是指：能用过去的价格历史提高期望收益。但正如 Fama 和 Blume (1966) 指出的：

"在漂移为零或为正的随机游走市场中，对单一证券应用任何机械交易规则，都无法持续跑赢简单地买入并持有。"

过去的价格变动只有在相继价格变化之间存在某种程度的依赖时才可能有用。序列相关系数未必能捕捉到可能存在的复杂依赖结构。下面我们简述几种常用的交易规则，并评述它们的表现。

为什么把这段放在滤波前面 这一段其实是给整节（乃至整章）先立靶子：随机游走 + 无套利 ⇒ 机械规则不可能赢。后面所有规则的命运都是在这个靶子上射箭——滤波是第一支箭，也是射得最偏的一支。注意那句话的精确条件："对单一证券""持续跑赢"——它没排除横截面规则（§5.9）和条件性小概率优势，这个缝隙后面所有策略都住在里面。

Fama–Blume 那句话的逐部件拆解——"在漂移为零或为正的随机游走市场中，对单一证券应用任何机械交易规则，都无法持续跑赢简单地买入并持有"：

部件精确含义
随机游走每天的收益是独立抽签：今天涨跌和昨天涨跌毫无关系。过去的价格不含有任何关于未来的信息。
漂移为零或为正抽签的平均值 μ ≥ 0——这只证券"平均来说不亏"。这是整个论断的关键前提（见下面手算，缺了它结论反转）。
单一证券规则只看这一只证券自己的过去（时序规则）。不覆盖"买 A 卖 B"的横截面规则（§5.9 的缝隙）。
机械交易规则过去价格 → 进/出/空的确定性映射（滤波、均线都是）。不能偷看未来，不能随意改主意。
持续跑赢不是某一次赢，而是期望意义上稳定地赢。排除"运气好碰上一段"的情形。
核心论证一行就够：期望收益 = 在场比例 × 漂移 随机游走下，每天收益的期望就是漂移 μ，且和你什么时候在场无关——哪天进场都一样，因为抽签不认日子。于是一条规则 N 天后的期望终值只取决于它在场的天数比例 f：

E[终值] = ef·μ·N　（买入持有 = f = 1 的特例）

μ ≥ 0 时 f 越大期望越高，而 f 最大就是 1（天天在场 = 买入持有）——所以任何规则最多打平，不可能赢。做空更是负贡献（空头收益期望 = −μ ≤ 0）。蒙特卡洛验证（20 万条路径、250 天、日 ±1%）：

· 零漂移：买入持有、在场 50%、在场 20% 的规则——期望终值全部等于 1.000，分毫不差地打平（差别只在波动的形状）；
· 正漂移 μ = 0.1%/天：买入持有 1.284，在场 50% 的规则 1.134，在场 20% 的 1.051——越挑剔越吃亏，因为每次离场都在错过正期望的抽签。

为什么必须写"漂移为零或为正"：若 μ < 0，"永远空仓"这条最平凡的机械规则期望 = 1 > eμN < 1，一句话就跑赢了买入持有——论断立刻不成立。所以这个前提不是可有可无的修辞，是结论成立的边界。

那滤波还赌什么？赌的正是"随机游走不成立"——现实中存在依赖结构（漂移在时段间切换，即后文 μt 的设定），规律一旦存在，"在场的日子"就不再是随机抽的，f·μ 这个乘积里，规则的 μ在场才可能高于整体的 μ。Fama–Blume 用道指数据宣判：现实里这点优势 < 佣金。

② 滤波规则的定义（Alexander 1961, 1964）

x% 滤波规则：若某日收盘价从近期低点上涨至少 x%，则买入并持有；直到价格从随后的高点下跌至少 x%，卖出并做空；维持空头仓位，直到价格从随后的低点上涨至少 x%，再买入。两个方向上幅度不足 x% 的波动一律忽略。

逐句拆：这条规则里只有三个活动部件 ① 跟踪两个锚——多仓期间跟踪"持仓期高点"，空仓/空仓观察期跟踪"近期低点"；② 一条触发线——锚点 ± x%；③ 一个状态机——空仓 → (涨过 x%) → 多仓 → (跌过 x%) → 空头 → (涨过 x%) → 多仓……

直觉一句话：x 是"噪音过滤器"。x 太小 → 随便一个抖动就触发，被假信号打死；x 太大 → 触发时趋势已走完大半，利润被迟到吃掉。所以它天然有个"最优 x"的问题——而这正是数据窥探的入口（§5.7 的伏笔）。

"最优 x = 数据窥探入口"是什么意思——一个蒙特卡洛演示（零漂移随机游走、1000 天、300 条路径，每条路径上把 x = 1%…20% 共 20 个值全试一遍）：

量结果
固定某一个 x 的平均累计损益+0.012 ≈ 0——市场真是随机的，任何单个 x 都没用 ✓（与 Fama–Blume 公理一致）
每条路径"20 个里挑最好"的赢家平均损益+0.385——是单个 x 的 30 倍
"赢家"盈利的概率97%
候选从 5 个扩到 20 个赢家平均损益 +0.294 → +0.400——试得越多，赢家越"好看"

读法：市场里根本没有信息，但只要你"试 20 个 x、挑回测最好的那个报业绩"，就能稳定造出一个看起来 97% 概率盈利、损益 30 倍于单规则的"策略"。它的全部利润来自选择本身的运气：20 个 x 在纯随机市场里的损益就是 20 次抽签，抽签总有最好的一个，而"最好的那个"天然偏乐观——挑出来的好 ≠ 真的好。

这就是"数据窥探的入口"：x 不是理论给定的，是试出来的；试的次数就是偏差的大小。§5.7 的 White Reality Check / SPA 就是给这笔账纠偏的工具——把"挑最好"这个动作本身放进 bootstrap 重演一遍，看真实赢家有没有超过纯运气的水平。历史判决（7846 条技术规则几乎无幸存者）就是这么算出来的。

诚实说明单个 x 平均 +0.012 而非严格为 0，来自我这份简化实现多空翻仓的微小不对称，量级仅为赢家的 1/30，不影响结论。

③ 背后逻辑与两次历史判决（p.162）

原书 p.162 · 逻辑与实证

这条规则背后的一般逻辑是：如果价格已经上涨了 x%，它很可能在下跌 x% 之前先上涨超过 x%——因此随机游走模型不太可能成立。但正如 Mandelbrot (1963) 指出的，由于成交瞬间的价格跳跃，实际的买入价和卖出价不会像规则要求的那样精确匹配。

该规则最初应用于 S&P 工业指数日线数据时显示：5%、6%、8% 滤波的总利润大于买入持有策略——但该研究没有计入交易成本。随后一项计入每回合 2% 佣金的研究表明：只有约 46% 的较大滤波跑赢了买入持有，其余滤波在调整交易成本后均不优于简单买入持有。

Fama 和 Blume (1966) 将 Alexander 的滤波技术应用于道琼斯工业平均指数每只成分股 1957–1962 五年间的日线数据，结论是：

"当计入佣金时，滤波技术下的大利润属于经纪人。若不计佣金，滤波技术的收益当然会大幅改善，但仍不及简单买入持有的收益。"

"利润属于经纪人"在数学上是怎么发生的 滤波是双向高频规则：一次完整的买卖回合至少要付两次佣金 + 买卖价差（Mandelbrot 那句"买价卖价不精确匹配"说的就是价差）。趋势行情里它赚的是"趋势中段"；震荡行情里它被来回打脸（下面的手算里你会亲眼看到一次 −6.6% 的假信号亏损）。趋势赚的钱是线性的，假信号亏的钱按触发次数累积——而市场大部分时间是震荡。所以扣费后的期望被成本项拖垮。这也是全书后续所有策略评估都要先问"费前还是费后"的原因。

用下面手算那笔账算给你看（按 Alexander 时代研究的口径：每回合佣金 2%；回合 = 一买一卖）：

交易回合毛损益加佣金后注
① 买 106 → 卖 99（day 3–7）−6.60%−8.60%假信号：正跌着被甩出去
② 空 99 → 回补 104（day 7–9）−4.81%−6.81%假信号的第二击：V 型反弹把空头也打脸
③ 买 104 → 卖 104（day 9–14）0.00%−2.00%白忙一场，纯付成本
④ 买 112 → 期末 113（未平仓）+0.89%（未结算）唯一吃到的一段趋势，还没走完
合计≈ −10.5%≈ −16.5%同期买入持有 = +13%

三笔假信号/磨损回合吃掉 17.4 个百分点，最后一段趋势只赚回 0.9 个百分点——成本和假信号是"按次数"计费的，趋势利润是"按幅度"计费的，而 20 天里次数远多于幅度。这就是"利润属于经纪人"的完整算术：经纪人拿走了 3×2% = 6% 的佣金，你拿到了 −16.5%。若再把价差算进去（每回合再让出买一卖一的差价），亏得更快。

④ 随机游走模型下的形式化（p.162 底部 – p.163 顶部）

原书 pp.162–163 · RW 表述

在随机游走（RW）模型下，多头仓位的平均收益理应约等于买入持有的平均收益——除非漂移恰好发生在入场或出场时点。滤波规则可在 RW 模型下表述如下：令收益 rt = ln Pt − ln Pt−1 = μt + at，其中 at 是零均值波动项，μt 是随机漂移项。按滤波规则，当 rt > r（阈值）时入场，设入场时刻为 t0。若漂移项恰好在 t0 被启动，即 t < t0 时 μt = 0，而 t ≥ t0 时 μt = μ > 0，则滤波的收益就会更好。漂移的持续时间需要仔细监测，且当 rt < r 时退出的策略能保证避免过度亏损。

当时间间隔很小时，已观察到收益中存在正依赖的证据，这或许可用于预测短期依赖。这可能意味着更频繁交易的机会，但交易成本会侵蚀利润。

μt + at 这个分解是全节的理论心脏 收益 = 漂移（方向） + 噪音（抖动）。滤波规则本质是一个漂移探测仪：它赌的是"涨幅超过 x%"这个事件更像"漂移启动了"而不是"噪音碰巧抖了一下"。

于是滤波赚钱的充要场景被说清楚了：你在场的时段里恰好覆盖了 μ > 0 的那些天。三种情形：① 漂移在入场后立刻启动且持续 → 滤波大赚（吃到 μ）；② 漂移启动在入场之前（你追进时趋势已老）→ 只吃到尾巴，还要付佣金；③ 漂移根本没启动（纯噪音越过阈值）→ 吃满一个假信号。历史判决"跑不赢买入持有"翻译过来就是：情形①的次数 × 平均 μ 盈利 < 情形②③的成本加亏损。

⑤ Sweeney 风险调整滤波（p.163）

原书 p.163 · Risk-Adjusted Filter

Sweeney (1988) 为"风险调整后的滤波"的利润检验设计了一套方法。Fama–Blume (1966) 中那些在某段时期是"赢家"的股票，往往在后续时期也持续是赢家——因此只聚焦于赢家而非全部股票能得到更好的结果。假设投资者每天仅凭过去信息用滤波规则决定进出场。考虑 N 天的跨度：滤波策略在 Nin 天持有该资产，在 Nout 天不持有。N 天结束时评估滤波的表现。买入持有的平均超额收益率为

定义
RBH = (1/N) Σt=1N (rt − rf)

设 f 为资产未被持有的天数比例，则滤波的平均超额收益率为

定义
RF = (1/Nin) Σt∈I (rt − rf)，　I = 持有日集合
逐符号读法：rt − rf = 第 t 天的超额收益（股票当天收益减去无风险利息——"承担股票风险比躺着多赚的部分"）；I = 滤波真正在场的那些天的编号集合，Σ 只把在场的日子加进来（空仓日不参与求和）；Nin = 在场天数 = (1−f)·N。所以 RF 读作："滤波在场的时候，平均每天多赚多少"。
代入手算那笔账（N = 19 天，在场 17 天，I = 除空仓 2 天外的其余日子，rf 记 0）：RF = 17 天对数收益之和 ÷ 17 = 0.00101/天——注意它不是滤波的真实赚钱速度（真实钱包要看摊薄口径的 X），它只是"在场期间的表现"这一个零件，是后面 (5.2) 的左半边原料。
和 RBH 的分工：RBH 分母是全部 N 天（买入持有天天在场，没有"挑日子"问题）；RF 分母是 Nin。两个分母不同，正是 (5.2) 要乘 (1−f) 对齐的原因。

假设在 CAPM 下，期望超额收益率等于一个常数风险溢价 PR。进一步设 E(RBH) = PR，E(RF) = (1−f)·PR。使用调整后的统计量

(5.2)
x = RF − (1−f)·RBH
来评判滤波规则；可验证 E(x) = 0，且 σx = σ / [(1−f)·N]1/2，其中 σ 是超额收益 rt − rf 的标准差。

Fama 和 Blume (1966) 使用的是

(5.3)
X = RFI − RBH
其中 RFI = (1/N) Σt∈I (rt − rf)（注意分母是 N 而非 Nin，即空仓日记 0 摊平到全部 N 天）。同样 E(X) = 0 且 σX = σ/√N。

X 的主要优点是它度量N 天里每一天的利润，而 x 度量的是持有股的那些天里每天的利润。上述结果对时变风险溢价同样成立：设 rf 之上的超额 = PR + at（at 随机），则

(5.4)
x = (1/Nin) Σt∈I at − (1/N) Σt=1N at + （PR 的两舱之差）
若投资者对风险溢价的变化没有洞察，则该溢价舱的期望为 0；若投资者对随机的 at 也没有洞察，滤波规则可能只是在"预测风险溢价"而非创造真 alpha。
诚实说明：这段原文的符号有两处损伤（PDF 文本层 + 原书排版） ① 原文说"f 为未被持有的天数比例"，但 (5.2) 里用的是 (1−f) 乘 RBH——要让 E(x) = 0 成立，(1−f) 必须是持仓比例（即原文 f 的定义与公式用法相反），本页按"公式自洽"的读法翻译；② (5.4) 的溢价舱在 PDF 里乱码（"PRNin+PRN"），我按结构补为"PR 的两舱之差"——它的作用只是说明：若两条收益路径的风险溢价舱相同，比较就只剩噪音舱。原文此段若对照 Sweeney (1988) 原始论文阅读更稳妥。

(5.2) 在想什么：先造一个"没有本事的世界"

"假设 CAPM 下期望超额 = 常数 PR"这句不是废话，它是在定义原假设世界：假如滤波毫无择时能力，那每一天的超额收益期望都是同一个数 PR——涨跌像抽签，日子不挑人。在这个世界里：

  • E(RBH) = PR：买入持有天天在场，拿到全额补偿，理所当然；
  • E(RF) = (1−f)·PR：滤波只有 (1−f) 份额的天数在场（摊到整个周期计），"没有本事"的它只能赚到运气份额——按在场比例打折后的 PR。

于是 (5.2) 的读法一句话：x = 实际赚到 − 没本事时应赚到。x > 0 ⇒ 挑日子的本事是真的；x ≈ 0 ⇒ 和瞎选没区别。E(x) = 0 不是算出来的结论，是刻意设计的锚点——整个统计量被造得在"无本事世界"里期望为零，这样实测 x 偏离 0 的程度才能直接读成本事的大小。

常见误读：E(x) = 0 的假设是"滤波赚的钱 = 超额收益"？——不是 这里要把"记账口径"和"行为假设"分开，两者经常被搅在一起：

① "用超额收益记账"是口径，不是假设。 RF 和 RBH 里的每一项都是 rt − rf——不管滤波还是买入持有，成绩一律按"扣掉无风险利息"计。这么定的理由：空仓的钱躺在无风险资产里也会生息，那部分谁都能拿到，不算本事，必须从两边同时扣掉，比较才公平。如果改用毛收益口径，锚点就歪了（买入持有会白赚一份利息，滤波被判"输得更多"）。

② E(x) = 0 真正依赖的假设只有一条：挑日子没有信息。 即"在场日"和"随便哪天"的期望超额一样，都是 PR。于是滤波的期望 = 在场比例 × PR = (1−f)·PR，与 (5.2) 右边的基准恰好相消 → E(x) = 0。

③ 它恰恰不假设"滤波赚得和超额收益一样多"。 注意 E(RF) = (1−f)·PR < PR——无本事的滤波拿的是打折后的超额（少在场就少赚）。若它真的假设两者相等，E(x) 反而 = −f·PR ≠ 0，锚点就废了。

一句话：超额收益是"尺子"，"挑日子无信息"是"原假设"，E(x) = 0 是两者合起来得到的锚点。而 (5.4) 的作用是把尺子再校一次——万一溢价本身在变（PR + at），正 x 可能是"挑到了高溢价的日子"（承担更多风险的报酬），仍不算本事。

σx = σ/[(1−f)N]1/2 是"运气的典型大小"：光知道 E(x)=0 不够，还得知道纯运气能把 x 推离 0 多远。分母的 (1−f)N 就是有效样本量（在场天数）——在场越久运气越被摊薄。这和你 5.7 学的"信号按 n 长、运气按 √n 长"完全同构：x ÷ σx 就是 t 值，手算例子里 x = −0.00475、σ = 1% 时 t ≈ −1.96，19 天就能显著判负。

(5.4) 是最后一道防线：如果"每天的风险溢价"本身在变（PR + at），那么滤波赚到的正 x 还有另一种解释——它不是在挑"会涨的日子"，只是在挑"风险溢价高的日子"，即收益是承担更多风险的报酬而非真本事。这就是"风险调整"三个字的完整含义：先把风险的份额从收益里剥干净，剩下的才有资格叫 alpha。

读法提示：总分口径 = 每天口径 × Nin，两者等价；(5.2) 是"每天、持有日、乘 (1−f) 对齐"，(5.3) 是"每天、全部 N 天、天然对齐"——x 与 X 的实测数字方向一致（都显著为负）、数值不同，正是口径不同的体现。

(5.2) 与 (5.3) 的区别：同一个问题，两种记账口径 两式都在回答"滤波比傻傻拿着好多少"，差别在怎么处理空仓日：

· (5.3) X（Fama–Blume 口径）：空仓日记 0，摊平到全部 N 天。问的是"这 N 天整体，滤波账户每天平均比买入持有多赚多少"。这是投资者真正的钱包视角——空仓日你拿着无风险利息（近似 0 超额），也是收益的一部分。
· (5.2) x（Sweeney 口径）：只算持有日，但右边乘上持仓比例 (1−f) 做风险暴露对齐。问的是"在场的那部分天，滤波每天的表现是否超过了它所承担风险应得的份额"。

两者在"规则无预测力"的原假设下期望都是 0，但检验功效不同：x 的标准差是 σ/√Nin（只由持有日的噪音决定），X 的是 σ/√N。哪个更灵敏取决于 f——空仓少时两者接近，空仓多时各有利弊。"和同等风险暴露的基准比，而不是和满仓基准直接比"——这是 (5.2) 的真正思想，它后来长成了整个基金业的绩效归因方法论（你在 §5.2 学的六个比率全都是这个思想的变体）。

四、这一节的遗产：对你项目的四条对照

本节的概念落到你的项目
"费前毛利漂亮 ≠ 策略好"（Alexander → Fama–Blume 的翻案）E1/E2 的 RankIC 和 CI 全是信号层指标，不含任何成本。论文里必须有一节把增量换算成费后——这正是路线图里 §6.5（交易成本）排在第一档的原因。
x 的选择 = 数据窥探入口（5%、6%、8% 哪个好是试出来的）你的 fraction（0.25/0.5）和窗口 20 天也是试出来的超参。§5.7 的教训直接适用：报告时说明选参过程，或对参数网格做一次 Reality Check 式的稳健性检验。
μt + at 分解（漂移探测仪视角）你的切割因子本质也是漂移探测：赌"大单日的收益模式"是结构（μ）而非噪音（a）。E1 的 CI 跨 0 = 数据不足以区分这两者——措辞按"无法证明有漂移"写，别写成"证明了没有"。
Sweeney 思想：和同等风险暴露的基准比你比较 E1 vs E0 用的是同一预测期、同一股票池的配对 bootstrap——本质上就是 Sweeney 式的"对齐后比较"。这条原则也可以往外推：未来若加仓位（§5.12 的 w），比较基准也要按 w 对齐，不能拿满仓信号和半仓信号直接比收益。
