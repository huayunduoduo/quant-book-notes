Section 5.12 · 中译注 + 逐条讲解

其他议题：下单规模等

Velu, Hardy, Nehren《Algorithmic Trading and Quantitative Strategies》· pp.202–204 · 公式 (5.56)–(5.64)

这一节回答一个前面所有章节都回避了的问题：决定了"买不买"之后，到底该买多少。全文逐段译出，九个公式逐个讲透，最后落到你项目里完全空白的那一块——仓位规模。

主旨一句话

第 5 章从头到尾都在解决"什么时候进、什么时候出"（方向）。这一节补上另一半："进多少"（规模）。并且给出两个完整解法——离散赌博框架的 Kelly 判据，和连续时间框架的 朱–周（2009）最优配置。

为什么这一节对你特别重要 你的项目现在只做了一半：evaluation.py 里的组合是月度 top 50、等权——也就是说，"买多少"这个问题你是用"平均分"糊过去的。

这一节正好是那一半的教科书。而且它还有一条对你很扎心的结论（式 5.64 后面那句）：如果状态变量对收益没有影响（μ₁ = 0），那么择时规则对"下多少"毫无帮助。

逐段中译（pp.202–204）

① 开篇：被默认掉的那个假设（p.202）

原书第 1 段

5.12 其他议题：下单规模等。

在上述交易策略中，一旦做出进出场决策，规模——即要买卖多少单位——通常被假定为投资的全部金额。许多交易者倾向于分批进场或出场，这样所有资金就不需要在某一时刻一次性投入或撤出。于是问题变成：如何确定每一笔交易的押注规模？我们在本节探讨一些实用的思路。

注解：它点破了一个被默认掉的前提 第 5 章前面每一条规则（过滤规则、移动平均、配对交易、横截面动量）的输出其实都只是一个方向：买 / 卖 / 不动。而"买多少"从来没被讨论过——默认答案是"全仓"。
这一节说：这个默认值是不成立的，规模本身就是一个需要求解的决策变量。

② Kelly 判据：下注多少分之一（pp.202–203）

原书第 2 段

一个归功于 Kelly（1956） 的判据，最初是在赌博的语境下提出的，它决定每一次应当押下的投资资本比例 f。设初始投资为 X0，共有 n 次投资机会，其依据的财富累积式为：

公式 (5.56)
Xn = X0 · (1 + f)W · (1 − f)L
X0 初始资本　·　n 下注次数　·　W 赢的次数　·　L 输的次数（W + L = n）
f 每次押下的资本比例：赢则这一份变成 1+f，输则变成 1−f
关于 (5.56) 的一处诚实说明 PDF 文本层在该式的指数部分有字符错位，无法逐字还原。此处按后续 (5.57)(5.58) 反推的标准形式给出——这是 Kelly 框架的标准写法，且与本节后面的推导完全自洽。
原书第 3 段（承上）

其中 W 与 L 分别为成功与失败的次数，p 与 q 为相应的概率。于是每次下注的增长率为：

公式 (5.57)
(1/n) · ln( Xn / X0 ) = p · ln(1 + f) + q · ln(1 − f)
把 (5.56) 取对数再除以 n。左边 = 每一次下注的平均对数增长率；右边 = 赢的情形与输的情形按概率加权
p = W/n　·　q = L/n　·　p + q = 1
公式 (5.58)
f* = p − q　（= (W − L) / n）
把 (5.57) 对 f 求最大化，解出的最优下注比例
这三个公式在干什么（形象版） (5.56) 是"钱包怎么变"：赢一次乘 (1+f)，输一次乘 (1−f)。所以你要的是"赢的次数尽量多"——但也别把 f 压得太小，那样赢得再多也没用。

(5.57) 换了个看问题的角度：不看"总钱数"，看"平均每一次下注，钱包的对数增长了多少"。为什么要取对数？因为财富是连乘的，取对数就把乘法变成了加法，n 次之后除以 n 就得到"平均每次"——这正是可以长期优化的量。

(5.58) 就是解出来的答案：最优比例 = 胜率 − 败率。
· 胜率 60% → f* = 0.6 − 0.4 = 20%，每次押两成
· 胜率 50% → f* = 0，别下注
· 胜率 40% → f* = −20%，应该站在对面下注

最反直觉的一点：哪怕你有 60% 的胜率（明显占优），也不应该全押——全押一次输光就归零了。Kelly 保护的是"能一直玩下去"。
原书第 4 段

为了在实践中实施，需要对 p 和 q 的良好估计；下注规模可以依据投资过程中对 W 与 L 的（近期）经验观察来修正。该问题的一个更一般版本，是在序贯博弈带有某种依赖结构时，求解最优下注向量 f* = (f*1, …, f*n)，但这看起来相当复杂。

这一句对你有直接的实操含义 Kelly 的输入是 p 和 q —— 胜率，不是打分。

你的 LightGBM 输出的是 score（一个可排序的分数），它不等于胜率。要用 Kelly，你得先把 score 校准成概率（比如用历史分位映射、Platt 校准、或 isotonic 回归）。

书里给的替代办法更实用：直接用近期实际观察到的赢／输次数（W、L）来滚动修正 f。这个你可以今天就在 evaluation.py 里实现。

③ 朱–周（2009）：把"也可以不投"算进来（p.203）

这一段在干什么（先给全局，再看公式，否则很容易迷路） 前面 Kelly 那一套有个没说出口的前提："不下注"就等于什么都不做，钱原地不动。

真实投资不是这样：你不买股票，钱没有消失，它可以躺在无风险资产里生利息。所以问题必须升级为——

"有风险资产 + 无风险资产，这两者怎么分？"

而且光说"我要收益最大"还不够——那只会导致满仓加杠杆（因为期望收益对仓位是线性的，投得越多期望越大）。所以必须再补问一句：你有多怕波动？这正是参数 γ 要登场的原因。

这一段就是把这个更真实的问题解出来。标题里那句"也可以不投"，指的就是无风险资产这个替代选项被纳入了决策。
四个公式的角色：它们不是四条并列的知识，是"解同一道题"的四件套
公式角色一句话
(5.59)目标函数你想最大化什么 → 期望效用
(5.60)约束条件钱是怎么变的 → 财富动态过程
(5.61)答案 · 简单版没有技术信号时的最优仓位
(5.62)答案 · 完整版把技术信号的信息算进来之后
看这一段最容易卡住的地方就是"这几个公式到底什么关系"——它们不是并列的四个知识点，而是同一道题的「目标 / 约束 / 解」。先认出这个结构，逐式再看就顺了。
原书第 5 段

统计套利规则的用途，可以扩展到进出场决策之外；但进出场决策的规模，必须在"投资于无风险资产"这类替代选项的存在下加以确定。朱与周（2009）表明：当未来收益存在不确定性时，固定配置规则可以通过技术分析得到增强。

固定配置规则来自第 6 章提出的投资组合理论。对于单一风险资产（其行为通过技术分析加以监控）与一种无风险资产，最优配置规则依第 6 章呈夏普比率结构：

教科书给出的基准解
w = ( μ − rf ) / σ
w 投在风险资产上的比例　·　μ 预期收益　·　rf 无风险利率　·　σ 收益标准差
μ 与 σ 由历史数据估计，并预期在近期保持稳定 —— 这就是"夏普比率"
原书第 6 段

假定投资者的初始财富为 X0，希望最大化期望值：

公式 (5.59)
E[ U(Xn) ] = E[ Xn1−γ / (1 − γ) ]
γ = 风险厌恶参数　·　这是标准的 CRRA（常相对风险厌恶）效用函数
γ = 0 → 完全不在乎风险（只看收益）；γ 越大 → 越怕波动；γ = 1 时该式退化为 ln Xn
(5.59) 手算一遍：γ 这个旋钮到底在拧什么 取 γ = 0.5，效用函数变成 U(X) = 2√X。看财富翻倍时效用怎么变：

期末财富 XnU = 2√X相比上一行增加了
100 万20.00—
200 万28.28+8.28
400 万40.00+11.72
注意：200→400 万也是翻倍，效用却只多 11.72（看着更大），但关键是"每单位财富带来的效用"在下降——100 万时每万元值 0.02，400 万时每万元只值 0.01。这就是"边际效用递减"，也就是"怕风险"的数学定义。

为什么必须有这一步？如果目标函数直接写成 E[Xn]，那么"投得越多期望越大"，最优解是无限加杠杆。效用函数的作用就是把"钱越多，每多一块钱越不值钱"这件事编码进去，从而让最优仓位变成一个有限的数字。

和前面 Kelly 的一个漂亮联系（我的观察，书上没明说）：γ → 1 时 CRRA 退化为 U(X) = ln X——而这正是 (5.57) 里 Kelly 最大化的那个东西。也就是说，Kelly 那一位投资者，本质上就是 γ = 1 的这位投资者。后面你会发现 (5.64) 里没有 γ，形式恰好对应 γ = 1 的情形，这不是巧合。
公式 (5.60) · 预算约束（财富的动态过程）
dXt = rf Xt dt + wt ( μ0 + μ1 St − rf ) dt + wt σ dBt
第一项：没投进风险资产的钱，按无风险利率 rf 增长
第二项：投进去的部分，赚到超额收益 μ0 + μ1St − rf
第三项：投进去的部分，承受波动（Bt 为布朗运动）
μ0、σ 为收益的均值与标准差；St 为状态变量，能提供关于未来股票收益的信息
(5.60) 手算一遍：一笔钱在一年里是怎么变的 先扫掉两个符号障碍：dt 就是"一小段时间"，dBt 是"这一小段时间里的随机冲击"（布朗运动的一小步，均值 0、标准差 √dt）。dXt = "这一瞬间财富变了多少"。

设：X0 = 100 万，rf = 2%，w = 0.5（一半投股票），μ0 + μ1St = 10%，σ = 20%。一年下来：

项算什么数值由谁决定
第一项
rfXtdt		 全部本金吃无风险利息 100 万 × 2% = +2 万 与你投多少无关，躺着也有
第二项
w(μ0+μ1St−rf)dt		 投进去的部分赚超额收益 50 万 × (10%−2%) = +4 万 正比于 w
第三项
w σ dBt		 投进去的部分承受波动 50 万 × 20% × 随机冲击 正比于 w，可正可负
看明白 w 出现在哪、不出现在哪，这一式就懂了：
· 第一项没有 w —— 不管你投不投，钱都在生利息。这就是标题说的"也可以不投"的收益底线。
· 第二、三项都有 w —— 你投得越多，赚得越多，抖得也越厉害。

所以仓位 w 本质上是在做一笔交换：用"多承担一点抖动"，换取"多拿一点超额收益"。最优 w 就是这笔交换最划算的那个点——而"多划算才算划算"由 (5.59) 的 γ 决定。
(5.60) 里唯一的新东西是 μ₁ · St 普通的配置问题里，预期收益就是个常数 μ0。这里多了一项 μ1 · St：意思是"预期收益会随状态变量 St 变化"。

St 是什么？就是你的技术分析给出的那个东西——移动平均的偏离、成交量的异常、任何你认为能预示未来的量。

μ1 就是"这个信号到底有没有用"的强度系数。μ1 = 0 意味着你的技术分析信号对收益毫无影响。整节最后的结论就挂在这个系数上。
公式 (5.61) · 收益随机时的固定配置率
w(γ) = ( μ − rf ) / ( γ · σ )
这就是经风险厌恶调整后的夏普比率。γ 越大 → 仓位越小；γ = 1 → 回到标准夏普比率
(5.61) 手算一遍：三个旋钮各拧一下看看 上面那个例子：μ = 10%、rf = 2%、σ = 20%。先算夏普比率 = (μ − rf)/σ = 0.08/0.20 = 0.40。于是 w(γ) = 0.40 / γ：

γ最优仓位 w这是什么样的人
0.580%激进，八成身家压上去
140%对数效用者 —— 就是 Kelly 那一位
220%稳健
410%非常保守
三个旋钮的作用方向一目了然：
· 分子 (μ − rf) 越大（超额收益越高）→ 仓位越大
· σ 越大（波动越大）→ 仓位越小
· γ 越大（越怕风险）→ 仓位越小

一句话记住：仓位 = 夏普比率 ÷ 你有多怕。注意 w 完全可以大于 1（加杠杆）——只要夏普比率够高、你又足够不怕（γ 小）。
公式 (5.62) · 把状态变量的信息算进来
w(γ) = ( μ − rf ) / ( γ σ ) + [ (1 − γ) / γ ] · d
第二项 d 是新增的修正项，由状态变量带来的额外配置
书中说明：d 依赖于 (5.60) 中的 μ1——它反映状态变量对收益过程的影响，以及状态变量自身的波动
当 γ = 1 时，第二项为 0，(5.62) 退化为标准夏普比率度量。
(5.62) 到底多了什么：一个"对冲未来"的仓位 相比 (5.61)，这里只多了一项 [(1 − γ)/γ] · d。直觉是这样的：

一旦你的信号能预示未来（μ₁ ≠ 0），"最优仓位"就不再是一个固定数字了——因为未来的投资机会本身会变。这时投资者除了"现在这笔划不划算"，还会多想一层："万一以后机会变差了怎么办？"这一层担心就是 d，金融学里叫跨期对冲需求（Merton 的经典结果，书上没展开）。

系数 [(1 − γ)/γ] 的符号很值得看一眼：
γ系数 (1−γ)/γ含义
γ < 1（不怕）正激进者愿意为"机会可能变好"加仓
γ = 1（对数效用）0刚好抵消 —— 对数效用者的"短视性"
γ > 1（保守）负保守者因"怕以后变差"而减仓
γ = 1 时这一项归零，不是巧合：对数效用投资者有个经典性质叫"短视"（myopia）——他只需要看当期最优化，不需要为未来的机会变化额外对冲。而 γ = 1 正是 Kelly 那一位。

⚠ 但千万别读错成"γ = 1 时择时就没价值了"。这里消失的只是 d 这个对冲项；信号的价值还会通过第一项里的 μ（漂移本身随 St 变）继续起作用——下一节 (5.64) 里那个 (μ₁/σ)(b₁/b₂) 就是它。
原书第 7 段（p.204）

d 这一项依赖于 (5.60) 中的 μ1，后者表示状态变量对收益过程的影响，以及状态变量中的波动；细节见朱与周（2009）。由于 d 可以取一系列不同的值，调整因子 [(1 − γ)/γ] · d 既可能为正，也可能为负。注意当 γ = 1 时，w(γ) = w，(5.62) 就导向夏普比率的标准度量。

④ 用一个具体的择时规则把它算出来（p.204）

原书第 8 段

为了评估"随时间跟踪价格以决定入场策略"的附加价值，我们遵循一条基于固定长度移动平均的简单规则。若当前价格 pt 大于移动平均值 At，则进入市场：

公式 (5.63)
ηt = η(pt, At) = 1　若 pt > At；否则 = 0
ηt 是入场指示变量：1 = 在场，0 = 空仓。这是全书最简单的一条择时规则
原书第 9 段

在此设定下，最优下注规模被证明为：

公式 (5.64)
w* = ( μ − rf ) / σ + ( μ1 / σ ) · ( b1 / b2 )
b2 = E(ηt)　—— 平均入场比例（有多大比例的时间在场）
b1 = E[ (St − S̄) · ηt ]　—— 入场时状态变量的平均超出量（只在场时，信号比平时强多少）
第一项 = 基准夏普比率仓位；第二项 = 择时规则带来的增量
原书第 10 段

其中 μ1 是"基于信息的状态变量 St"对价格形成的影响，b2 为平均入场次数，b1 给出状态变量的平均超出量。虽然 (5.64) 中的其他量在历史上已被充分研究，这里新的关键比值是 (μ1/σ) · (b1/b2)，它可以被视为"可以分摊到 b2 次入场上的总规模 (μ1 · b1)"。

如果 μ1 = 0，注意移动平均规则可能不会给固定规模的入场带来任何灵活性。

(5.64) 精讲：这一步在干嘛、每个符号是什么、数字怎么算 先定位：④ 段在整节里干的事。③ 段给的 (5.62) 是个抽象答案——里面有个说不清道不明的 d。④ 段的工作就是：挑一条最简单的具体规则（5.63），把抽象答案算成看得见的数字——d 落地成 (μ₁/σ)·(b₁/b₂)。

第 1 步 · (5.63)：把"择时"变成一个开关。ηt 只取 0 或 1：价格在均线上方 = 1（在场），下方 = 0（空仓）。它的作用是把"你什么时候在场"变成一个可以代入期望运算的数学对象。注意：η 是由信号决定的——你只在"信号说好"的时候在场。

第 2 步 · 逐符号表：
符号定义直观读法
μ − rf无信号时的超额收益第一项的分子——底仓的"报酬"
μ1信号每强 1 单位，预期收益多多少信号的"价值密度"——整个第二项全挂在它身上
b2 = E(ηt)入场指示的平均值在场时间比例（1 = 天天在场，0.5 = 一半时间）
b1 = E[(St−S̄)·ηt]信号偏离 × 入场开关 的期望只在场时才计入"信号比平时强多少"——空仓的时段不算
第一项没有 γ：这正是 ③ 段说的"γ = 1 的情形"——(5.64) 是对数效用（也就是 Kelly 那一位）视角下的答案。

第 3 步 · 一个让公式瞬间变直白的化简（观察，原书没明说）：
b₁ ÷ b₂ = E[(St−S̄)·ηt] ÷ E[ηt]，分子分母正好构成条件期望：

b₁/b₂ = E[ St − S̄ | 在场 ]　——"你入场的时候，信号平均比平时强多少"

于是 (5.64) 可以读成一句大白话：最优仓位 = 底仓 + 信号价值密度 × 入场时的信号优势。每多承担一份波动（÷σ），你在真正入场的那段时间里，凭信号多赚 μ₁ × (b₁/b₂)。

第 4 步 · 手算一遍：设 μ − rf = 8%，σ = 20%，μ₁ = 0.10。20 天里 η=1 的有 8 天 → b₂ = 8/20 = 0.4；在场那 8 天信号平均超出量 +0.8（空仓 12 天是 −0.5，但乘 η=0 不计入）→ b₁ = 0.4 × 0.8 = 0.32。

对照：如果信号无效（μ₁ = 0），第二项 = 0，w* 恒等于 0.40——规则开关得再勤快，仓位都是 40%，择时白做。这就是下一框那句扎心结论的数学来源。
第二项归零有两条路——第二条更隐蔽，也更值得你警惕
情形第二项含义
μ₁ = 0：信号对收益无影响= 0信号本身没价值，规则怎么设计都救不了
b₁ = 0：信号有用，但你入场时它并不比平时强= 0规则和信号"没对上表"——比如均线规则恰好总在信号弱时触发
两者都 ≠ 0> 0择时才有真增量
b₁ = 0 这条路平时没人提，但它回答了一个重要问题："信号有用"为什么还不等于"策略有用"？因为价值 = 信号价值 (μ₁) × 规则与信号的配合度 (b₁/b₂)——两个因子相乘，任何一个为 0，乘积就是 0。检验一个策略，这两件事要分开测：先测 μ₁（你的 E1/E2 干的就是这个），再测你的入场规则是否真的在信号强时触发。

落到项目：St 就是你的切割因子。E1/E2 测不出增量 ≈ μ₁ ≈ 0 → 按 (5.64)，建立在它之上的任何仓位/择时规则都不会有价值——这就是那条可以写进论文的连锁负结论。反过来，若以后某个信号测出 μ₁ ≠ 0，先别急着做策略——还要验证你的调仓时点真的落在信号强的时段（b₁ > 0），两个都过了才算数。
整节最重要的一句，就在最后这一行 "如果 μ₁ = 0，移动平均规则可能不会给固定规模的入场带来任何灵活性。"

翻译过来：只有当你的信号真的能影响未来收益（μ₁ ≠ 0）时，择时规则才会改变"该下多少"。如果你的信号跟未来收益无关，那么不管你的进出场规则多花哨，最优仓位都还是那个固定的夏普比率仓位——择时白做。

对照你的结果：你的 E1 增量测不出来，等价于在说"切割因子对收益的影响接近 0"。按这一节的逻辑，那就不只是"因子没用"，而是——建立在它之上的任何择时/调仓规则，都不会带来仓位上的额外价值。

两条诚实边界 ① 这一节的理论假设很重。(5.59)–(5.64) 假设收益服从带漂移的布朗运动、μ 与 σ 在近期稳定、投资者效用是 CRRA 形式。这些在 A 股都不严格成立。所以这些公式的价值是告诉你"仓位该由哪几个量决定"，不是给你一个能直接抄的仓位数字。

② Kelly 有一个著名的实践陷阱。f* = p − q 对 p 的估计误差极其敏感：高估胜率会导致过度下注，而过度下注的代价（长期几何增长率下降、回撤剧增）远大于低估。业界通行做法是"半 Kelly"或更保守（用 f*/2 甚至 f*/4）。这一节没有提这一点，但你必须知道。
