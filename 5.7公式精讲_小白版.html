Section 5.7 · 公式精讲

5.7 里的六个公式，一个一个拆开讲

原书 Algorithmic Trading and Quantitative Strategies · pp.171–173 · 公式 (5.27)–(5.32)

这一页只干一件事：把书上那六个公式的每一个符号翻译成人话，然后用一个 5 天、3 条规则的小例子，把数字一步步算出来给你看。看完你不仅能读懂公式，还能自己手算一遍。

先说一句让你安心的话

这六个公式看起来吓人，其实只有三件事：① 怎么给一条规则打分（5.28）；② 怎么把很多天的分平均起来（5.27）；③ 怎么判断"这个分是不是运气"（5.29–5.32）。剩下的全是符号的花样。

书上的顺序会让你卡住 书上先印 (5.27) 再印 (5.28)，但 (5.27) 里用了 (5.28) 才定义的东西。理解顺序要反过来：先看 5.28（一天怎么打分），再看 5.27（把 n 天平均）。这一页就按好懂的顺序讲。

第 0 关符号破译：先把这堆符号认全

公式看不懂，八成不是数学难，是符号不认识。下面这张表把本节所有符号列全了。建议先扫一遍，回头看公式时对照着查。

符号念什么人话
t"现在"你站在今天这个时点。所有规则、所有决策，只能用 t 之前的数据。
n期数你要验证的未来有多少天。t+1 到 t+n，一共 n 天。
j第 j 天在 t 之后的第 j 天，也就是 t+j。只是个循环计数器。
rt+j收益率第 t+j 天市场的涨跌幅。+0.01 就是涨 1%。
sk信号第 k 条规则给的仓位指令。只有三个值：做多 = 1，做空 = −1，空仓 = 0。
s0基准信号拿来对比的那个"参照规则"。书上常取"始终空仓"，即 s0 = 0。
k第 k 条规则的编号，k = 1, 2, …, l。
l规则总数你一共考察了多少条规则。Sullivan 等人那篇用了 l = 7846。
fk,t+j单日得分第 k 条规则在第 t+j 这一天，比基准多赚了多少（对数口径）。
f̄kf bar第 k 条规则在 n 天里的平均每日得分。上面那一横 = 取平均。
̂f (f 上面戴帽子)f hat表示"估计出来的"，不是真实值。真实值永远不知道，只能估。
*星号表示"这个数是 bootstrap 假造的"。凡是带星号的，都来自重抽样，不是真实历史。
i第 i 次第 i 次重抽样。一共抽 B 次，i = 1, 2, …, B（B 常取 1000）。
√n根号 n一个"放大镜"，把日均得分换算成"攒了这么多天的证据强度"。后面单独讲。
maxk=1..l取最大在 l 条规则里挑分数最高的那条。这是多重检验的命门。
E[·]期望"如果无限重复，平均会是多少"。可以理解成这条规则的真实水平。
H0原假设"被告是无辜的"那个假设。统计检验默认它成立，直到证据足够推翻它。
两个符号习惯，记住就不会再懵 ① 戴帽子 = 估计值。凡是 f̂（f hat），都在提醒你"这是用样本算出来的，不是真相"。
② 带星号 = 假数据。凡是 f*（f star），都在提醒你"这是 bootstrap 造出来的平行世界，不是真实历史"。

第 1 关公式 (5.28)：一条规则，一天，怎么打分

这是整个小节的地基。后面所有公式都是它的变形。搞懂这一个，后面五个都好办。

(5.28)
fk,t+j  =  ln( 1 + rt+j · sk )  −  ln( 1 + rt+j · s0 )
左边：第 k 条规则在第 t+j 天的得分。右边：这条规则的对数收益，减去基准的对数收益。
人话版（一句话）

「你按这条规则下单，今天赚的（对数）收益，减去如果你按基准操作能赚的（对数）收益。」——差就是这条规则今天"额外贡献"了多少。

把它拆成三个动作，一步步走

1
市场给你一个收益 r
比如今天市场涨 1%，那么 r = +0.01。这一步跟你的规则无关，是市场给的。
2
乘上你的仓位 s，得到"你的收益"
  • 你做多（s = 1）→ 你的收益 = r = +0.01，跟着市场赚
  • 你空仓（s = 0）→ 你的收益 = 0，不赚不亏
  • 你做空（s = −1）→ 你的收益 = −r = −0.01，市场涨你亏
一个乘法就把三种仓位全处理了，这就是 s 只取 1 / 0 / −1 的巧处。
3
取 ln(1 + …)，再减去基准的同样一项
先取对数变成"对数收益"，再把基准的减掉。减完的结果才是这条规则的净贡献。
公式 (5.28) 的三个动作。基准取空仓时，最后一步的减法就不起作用了。

为什么非要取 ln？直接减不行吗？

理由一：对数收益可以相加，普通收益不行 今天涨 10% 明天跌 10%，你的真实结果是 1.1 × 0.9 = 0.99，亏了 1%，不是打平。但如果用对数：ln(1.1) + ln(0.9) = 0.0953 − 0.1054 = −0.0101，正好约等于亏 1%。
→ 因为我们要把 n 天的得分加起来再平均（这就是 5.27），所以必须用能相加的口径，否则平均出来的数是错的。
理由二：做空的时候不会算出"负的本金" 做空时 s = −1，你的收益是 −r。万一某天市场暴涨 150%（现实中少见，但理论上有），直接算收益会变成 1 + (−1.5) = −0.5，本金成了负数，再取对数就报错了。
→ 用 ln(1 + r·s) 这个写法，配合实际收益率范围，能保证括号里恒为正。数学上更稳。
理由三：它衡量的是"钱的复合增长"，跟长期收益直接挂钩 对数收益加起来 = 你这段时间资金曲线的总增长。所以最大化对数收益，等价于最大化长期复合收益。
→ 这也是为什么它和夏普比率能放在同一个框架里比较（书上说"同样的假设也可以对夏普比率来提"）。
顺手记住这个近似 当 r 很小的时候（日频数据基本都满足），ln(1 + x) ≈ x。
所以 ln(1.01) = 0.00995 ≈ 0.01，差别只有万分之五。你心算的时候直接拿 r·s 当近似值就行，不会错到哪去。

一个小陷阱：s 只能用"当时已经知道的信息"

书上原话的隐含条件 书上写："信号函数当然只能基于截至 t 时刻可得的数据与信息。"

这句话是整节的合规底线。意思是：第 t+j 天的仓位 s，必须是用第 t+j 天开盘之前的数据算出来的，不能偷看当天收盘价。

这跟你项目里的 PIT 问题是同一件事——你新闻数据那个 published_at 和 available_at 的区分，还有撮合引擎时间和接收时间的区分，都是在守这条线。一旦 s 偷看了未来，f 就是假的，后面所有检验全部作废。

第 2 关公式 (5.27)：把 n 天平均起来

(5.27)
1n  ·  Σj=1..n   f̂t+j   =   f̄
Σ（sigma）= 求和。整式的意思是：把 t+1 到 t+n 这 n 天的得分加起来，再除以 n。
人话版（一句话）

「这条规则平均每天比基准多赚多少。」

为什么要平均，而不是看总和？ 因为总和没有可比性。你把一条规则跑 100 天的总分，和跑 1000 天的总分放在一起比，毫无意义——后者天然更大。
平均掉天数以后，"每天多赚 0.05%"这个数就跟跑了多久无关了，可以直接横向比。
为什么书上写的是 f̂t+j（没有下标 k）？ 因为 (5.27) 是在说"任意一个绩效度量怎么平均"，还没特指哪条规则。到了 (5.30)，它就会写成 f̄k，带上 k 表示"第 k 条规则的平均分"。同一个 f̄，加不加下标 k，取决于在不在讨论多条规则的场合。

第 3 关公式 (5.29)：原假设到底在说什么

(5.29)
H0 :  maxk=1..l   E[ fk ]   ≤   f0
原假设：所有 l 条规则里最好的那条，它的真实水平也不比基准强。
人话版（一句话）

「这 l 条规则里，没有一条是真的有本事的。你看到最好的那条好看，纯属走运。」

这里有两个"反直觉"，必须讲清楚

回看 (5.29)，里面其实只有两个特别的记号：max 和 E[·]。下面两张卡片，各是一张"记号说明书"——不先说清楚，你几乎必然会把这两个记号读错，而读错的代价是后面整节都白看。

反直觉一：max —— 原假设是"全都烂"，不是"这条烂" 先看一个抛硬币的例子。让 1000 个人每人抛 10 次硬币。哪怕人人都是乱抛，"正面次数最多的人"也很可能抛出 9 次。你能说他是"抛硬币高手"吗？不能——他只是1000 人里运气最好的那一个。"从一堆人里挑冠军"这个动作，本身就一定会制造出好看的成绩。

现在回到公式。普通 t 检验问的是"这一条规则行不行"；这里的 max 让它一次性问"这 l 条里，最好的那条行不行"。

为什么要这样？因为你真正会拿去用的，就是挑出来的那条最好的。检验的对象必须是你实际会做的那个动作——而"从一堆里挑最好的"本身，就是你这个动作的一部分。

如果只检验单条，那你挑 7846 条里最好的一条去检验，等于只验运动员、不验选拔赛——把"挑选"这个动作偷偷排除在检验之外了，作弊。
反直觉二：E[·] —— "真实水平"和"你看见的成绩"是两个数 先看一个投篮的例子。一个球员这个月命中率 60%。"这个月 60%"（你看见的）和"他的真实水平"（看不见的）是两个数——这个月 60%，可能是他真实水平就高，也可能只是超常发挥。

公式里同理：E[fk] 是这条规则在无限长的时间里平均能赚多少——这是你永远不知道的真相。
f̄k 是它在你这 n 天样本里实际赚了多少——这是你能看见的。

麻烦在于：你只能看见 f̄，永远看不见 E。两者的差，就是运气。整个 5.7 节做的事情只有一件：估算"运气能把 f̄ 抬高多少"，然后看你的 f̄ 有没有超出这个范围。

如果不区分这两个概念，你会直接拿 f̄ 下结论——"日均多赚 0.5%，所以有本事"——这就把运气当本事了。
这两张卡是后面所有内容的地基 记住这层对应：(5.31) 里减掉 f̄k，减的就是"你看见的"，把平行世界强行搬到"真实水平 E = 0"（大家都没本事）的世界里；而 max 出现在原假设里，所以 bootstrap 时也要在 l 条规则里取 max——"运气能撞出的最好成绩"，本来就是 max 的运气。

第 4 关公式 (5.30)：那个 √n 是干嘛的

(5.30)
vl  =  maxk=1..l  (  √n  ·  f̄k  )
检验统计量：把每条规则的平均分乘上根号 n，再取最大的那个。
人话版（一句话）

「把这 l 条规则里最好的那个成绩，放大到'证据强度'的尺度上。」

先建立一个画面：真本事和运气，长得不一样快

假设一条规则真有点本事，每天平均多赚 μ = 0.5%；而市场每天的随机波动是 σ = 2%。现在看"观察 n 天之后，这两样东西各自攒了多少"：

观察天数 n真本事攒下 μ×n运气攒下 σ×√n谁占上风
5 天2.5%4.5%运气盖过真本事，看不出来
16 天8.0%8.0%平手，分界点
25 天12.5%10.0%真本事刚冒头
100 天50%20%真本事是运气的 2.5 倍
500 天250%44.7%真本事是运气的 5.6 倍
为什么运气只按 √n 长？ 因为涨跌会互相抵消。今天 +2% 明天 −2%，两天加起来不是 ±4%，而是更接近 0。数学上，n 个独立随机量相加，总幅度按 √n 增长，而不是按 n。

真本事不一样——它每天都往同一个方向贡献 0.5%，不会抵消，所以老老实实按 n 线性累加。

于是两者的比值就是：

真本事 ÷ 运气  =  ( μ × n ) ÷ ( σ × √n )  =  ( μ / σ ) × √n

这个 √n，就是从上面那个除法里掉出来的。n 翻 100 倍，比值才翻 10 倍。

那 √n 在公式里到底干了什么

把 f̄k（日均得分）拆成两块看：

f̄  =  真本事 μ  +  运气（幅度 σ/√n）
运气那一块幅度是 σ/√n：n 越大越准，这就是"取平均能消噪"。真本事那一块就是 μ，不随 n 变。

现在两边同时乘上 √n：

√n × f̄  =  √n × μ  +  σ
左边绿色那块随 √n 变大，右边橙色那块被钉死了，再也不随 n 变。
这就是整个操作的目的 乘 √n，等于把"运气的音量旋钮"固定住。

之前：真本事和运气混在一起，你不知道看见的 0.5% 里各占多少。
之后：运气那一块被标准化成固定大小 σ，于是统计量上剩下的刻度，纯粹就是真本事的强度。

类比：收音机里有个很弱的台，信号和杂音混在一起。√n 就是把杂音音量锁死，这样音量表上的读数才只反映信号强弱。

那为什么不是乘 n？

乘 n 会让噪声跟着一起涨，永远定不下临界值 如果乘 n：n × f̄ = n×μ + n×(运气)，运气那一块的幅度会变成 √n × σ——随着 n 一路涨，永不停。

后果：观察天数一变，这个统计量的波动幅度就变，那"临界值"就没法给出一个通用数字，不同研究之间也没法比。

乘 √n 之后，波动幅度被固定成 σ，分布形状不再随 n 大幅变化（这是中心极限定理的直接结果）。分布稳定了，临界值才能定下来，bootstrap 也才好模仿这个分布。

这就是书里写 √n 而不是 n 的原因。

一句话记住

√n 是"含金量放大镜"

同样是"日均多赚 0.5%"，观察 5 天和观察 500 天，含金量差 √(500/5) = 10 倍。而 f̄ 这个数本身看不出这个差别——乘上 √n，差别才显式地写出来。

落到你项目上：把这句话拆开

先说公式是哪来的，三步：

1
标准误 SE = σ / √n
σ 是单个观测的波动（你每天那个增量本身的抖动）。n 是观测天数。SE 衡量的就是"你算出来的这个平均值，有多大不确定性"。
2
95% 区间 = 估计值 ± 1.96 × SE
1.96 没什么神秘的：正态分布下，95% 的概率落在 ±1.96 个标准差以内。换个置信水平就换个系数。
3
宽度 = 2 × 1.96 × σ / √n
把上一步的两倍算出来，就是这句话里的公式。width 与 √n 成反比——这就是为什么 n 翻 4 倍，宽度才减半。
为什么是 √n 而不是 n（一句话复述） 平均值的误差按 √n 缩小，所以想让精度翻倍，就得付 4 倍数据。这就是"边际收益递减"。

先别急着算：「这个区间」到底是什么

你项目里那个区间，测的不是 RankIC 本身，也不是某一天的涨跌。它测的是这样一个东西：

对每一个交易日 t，都算一个差值：

dt = RankIC(E1, 第 t 天) − RankIC(E0, 第 t 天)

你一共有 n = 856 个这样的 d，它们的平均是 −0.001297。这个平均就是点估计——你最好的一个猜测。

区间 = 撒出去的一张网 点估计是一个点，但它有误差，所以你不敢说真值正好等于它。

于是你在它周围撒一张网：网的范围就是置信区间。网撒得越宽，说明你越不敢确定。

−0.001297 是"我猜是这个数"；[−0.006907, +0.003756] 是"真值可能在这么大一片里"。
95% 到底在说什么（这句话最容易讲错） 错误的说法："真值有 95% 的概率落在这个区间里。"
正确的说法："如果这套做法重复很多次，这样造出来的区间里，有 95% 会盖住真值。"

差别在于：真值是一个固定的数，不是随机变量；随机的是这张网——你换一批日子重算，网的位置和大小就变了。

类比：渔夫说"我这套撒网手法，100 次里有 95 次能罩住鱼"。鱼没在动，动的是网。

为什么"跨 0"这么要命 区间中间那条红线是 0 = 切割因子完全没用。

区间把 0 包进去了 → "可能没用"这个选项还没被排除，所以你不能说它有用。
区间整条在 0 右边 → 连"没用"都被排除了，才谈得上有用。

你的 E1、E2 两条区间都把 0 包在里面，所以结论都是"不能说有用"。区别只在于：E1 的网大到连方向都说不清，E2 的网很小，能确定"就算有用也小到没意义"。

为什么判据偏偏是"不跨 0"

因为 0 有一个精确含义：加了等于没加 你的 dt = RankIC(E1) − RankIC(E0)，是"加了切割因子以后，RankIC 变了多少"。

如果切割因子一点信息都没有，那它加进去跟没加一样，这个差值的真实平均值就应该正好是 0。

所以 0 不是随手画的线，它是"这个因子毫无用处"这句话的数学写法。
判据背后是一条法律原则：无罪推定 你要证明的是"这个因子有用"，但统计不允许你直接证明它——它只负责帮你排除"没用"。

法庭类比：不能因为"他看起来有点像凶手"就定罪。必须先把"他是无辜的"这个可能性排除掉，才能判有罪。

新药类比：一款新药必须证明"比安慰剂好"。如果测得的效果是 [−2 分, +5 分]，包含 0 —— 意思是"也可能跟糖片一样"，药监局就不批。

区间跨 0，就是"没用"这个可能性还好好地坐在里面，你排除不掉它。排除不掉，就不能宣布有用。
一句等价，答辩时能救命
置信区间的说法假设检验的说法
95% 区间不跨 0双尾检验 p < 0.05
95% 区间跨 0双尾检验 p ≥ 0.05

这不是两个判据，是同一件事的两种说法。所以你看到"p 值"和看到"区间跨不跨 0"，得到的结论永远一致。

两个必须自己加上的警告（不跨 0 ≠ 有用） ① 还有 5% 的假阳性。"不跨 0"的保证是：如果因子真的毫无用处，你有 95% 的概率正确地说"说不清"，但仍有 5% 的概率会错误地宣布"有用"。
更严重的是：你同时看了 E1 和 E2 两条（甚至更多），每看一条就多一次 5% 的机会。三条一起看，至少一条假阳性的概率约 14%，不是 5%。这正是 5.7 节 White / SPA / FDR 要解决的问题。

② 统计显著 ≠ 经济上有意义。假设以后数据多了，E2 的区间缩到 [−0.0009, −0.0001]——不跨 0 了，"显著"了。
但 RankIC 提升 0.0001，扣掉双边千一到千三的费用，一分钱都不剩。所以你手册里要求 RankIC 和费用后 CAGR 一起报，就是为了堵这个洞。

两个减号不是一回事（你抓得很准）

你可能会问：dt = RankIC(E1) − RankIC(E0) 里明明也有减号，为什么说"判断是不是 0 需要 (5.31) 那个减号"？

因为这是两个完全不同层次的减法：

减号 ①（你代码里的）减号 ②（(5.31) 里的）
减在哪 数据层，每一天各减一次 统计量层，每次重抽都要减
减的是谁 另一个模型（E1 减 E0） 它自己（f̄*k 减 f̄k）
解决的问题 剔除当天大盘涨跌这个两人共有的因素，让比较变成"同一条跑道" 把平行世界搬到"真值 = 0"的世界里，才问得出"是不是 0"
回答什么 "增量是多少" "增量是不是 0"
一句话区分 减号 ① 是把两个选手放在同一天比，消掉赛道难度差异；
减号 ② 是把整条赛道的原点挪到"零差距"，然后问"这个成绩算不算超常"。

你做了 ①，所以你知道"差 −0.0013"；但 ① 不会告诉你这个 −0.0013 有没有超出运气范围。
顺便更正我前面一句说得太绝对的话 我前面写"置信区间不回答'是不是 0'"——这句话说过头了，谢谢你抓住。

准确的说法是：对单个参数，置信区间和检验是"对偶"的。
数学上：θ₀ 不在 (1−α) 置信区间里 ⟺ 在水平 α 下拒绝 H₀: θ = θ₀。
所以当原假设正好是 0 时，"区间不跨 0"和"p < 0.05"就是同一件事（这也是上一节那张表的依据）。

真正会断掉的是这三种情况：
  1. 多条一起检验。你同时看 E1、E2——原假设变成 max E[fk] ≤ 0，是"最好的那条"而不是"这一条"。单条 CI 完全失效，必须用 (5.31) 那套"中心化 + 取 max"的 bootstrap，也就是 White / SPA。
  2. 要的是校正后的判据。做了 FWE 或 FDR 校正后，临界值不再是 1.96，单条 CI 的宽度对不上。
  3. 关心的是经济阈值而不是 0。比如问"增量是否 > +0.002（够不够覆盖双边费用）"——这时要看的是区间下界 vs 0.002，不是"跨不跨 0"。

底牌：把这些公式一次性摊开

图里每根横条，背后只有下面这条链。每一步都在上一步后面加一样东西，没有一步是凭空冒出来的。

步公式它在说什么
① Var(x̄) = σ² / n n 个观测相加，方差累加 n 次得 nσ²，再除以 n²。独立让所有协方差项变成 0，否则这一步不成立
② SD(x̄) = σ / √n 把 ① 开方，这就是标准误 SE。√n 是在这一步第一次出现的
③ CI₉₅ = x̄ ± 1.96 · σ/√n 正态分布下 95% 的概率落在 ±1.96 个标准差内。1.96 = 标准正态的 97.5% 分位点（z0.975 = 1.959964）
④ W(n) = 2 × 1.96 × σ/√n = 3.92σ/√n 全宽 = 上界 − 下界，± 各占一份。图里每根条的长度就是这个 W
⑤ W(n₂) / W(n₁) = √(n₁ / n₂) 两个 W 相除，3.92 和 σ 全部约掉，只剩 √n。这就是图上 ÷1.41 / ÷2 / ÷2.83 / ÷4 的来历
⑥ n₂ = n₁ · (W₁ / 2m)² 反解：要让半宽 W/2 小于效应量 |m| 才不跨 0。代入你的数：856 × (0.010663 ÷ 0.002594)² ≈ 14 464 天
第 ① 步那个"独立"，是你项目里最大的坑 ① 成立的前提是 n 个观测互不相关。你的标签是 20 日重叠的——相邻两天共享 19/20 的信息，协方差项不为 0。

严格写法要乘一个膨胀因子：
Var(x̄) = (σ²/n) · (1 + 2·Σk≥1 ρk)

其中 ρk 是滞后 k 阶的自相关。重叠 20 天意味着 ρ1…ρ19 都很接近 1，这个括号会变得很大。

好消息：你不用自己算它。循环移动块 bootstrap（block = 21）就是用"整块整块地重抽"来把这个膨胀因子连同分布形状一起测出来，所以你的区间已经是付过账的版本。

所以"必须报 n"到底在报什么

  • 报 n，等于报"这个结论有多稳"。同样看到 −0.0013，n = 200 的人是"什么都不知道"，n = 856 的你是"证据不足但方向明确"，n = 5000 的人才有一点资格谈结论。
  • 报 n，别人才能反推 σ。区间宽度里藏着 σ，但 σ 本身没写出来。有 n 和宽度，就能反算数据波动有多大，判断你的样本质量。
  • 报 n，评审才能判断覆盖度。856 天 ≈ 3.4 年，只经历了一轮牛熊的一小段。样本期覆盖了哪些市场状态，比 n 本身更重要。
  • 报 n，才能暴露"有效样本"问题。856 个日度观测，扣掉 20 日重叠后真正独立的只有约 856/21 ≈ 41 块。41 个独立单位，这才是你这个结论的真实信息量。

插播bootstrap 到底是什么

前面一直在说"重抽样""平行世界"，却从没解释过 bootstrap 本身。不搞懂这个，(5.31) 一定看不懂。这一节只讲本质。

一句话本质

你手上只有一份数据，却想知道"如果重来一次会怎样"。bootstrap 说：那就把你这一份数据当成整个世界，从它里面反复抽。

名字来自英语 pull yourself up by your own bootstraps（拽着自己的鞋带把自己提起来）——用自己仅有的数据，把自己提起来。

它要解决的那个死结

统计学里几乎所有有用的东西——误差、置信区间、p 值——都需要知道"这个统计量的波动有多大"。

而"波动"按定义就需要很多份样本：同一件事重复做 1000 次，看结果散得多开。

死结：历史不能重来 你只有一份历史。你没法让 2024 年再走一遍，看看"另一种运气"下你的策略会怎样。

一份样本，测不出波动。

它怎么解开：三步

1
把样本当成整个总体
你手上这 n 个观测，就是你对"真实世界长什么样"的最好猜测——事实上也是唯一的猜测。所以，从样本里抽，近似等于从真实世界里抽。
2
有放回地抽 n 次，得到一个「伪样本」
注意是有放回：摸一颗、记下、放回去、再摸。所以同一个观测可能被抽中好几次，也可能一次都没被抽中。
3
重复 B 次（通常 1000 次以上）
每个伪样本算一遍你关心的统计量，得到 B 个值。这 B 个值的分布，就是你要的那个"波动"。数一数有几个超过你的真实值，除以 B，就是 p 值。
一次重抽。重复 1000 次，你就有了 1000 个"平行世界"。

为什么「有放回」是灵魂

如果不放回会怎样 无放回地抽 n 个，抽出来的必然是原来那 n 个，只是顺序变了。而顺序不影响统计量——每次算出来一模一样，B 次全一样，波动是 0。等于白抽。

有放回才有重复、有缺席，样本的组成才会变，统计量才会变。
整个 bootstrap 的信息，全部来自"有放回"这三个字。

为什么这样做是合法的

唯一的前提：样本的分布 ≈ 总体的分布 bootstrap 的全部合法性，建立在"你手上这份数据的经验分布，是真实分布的一个好猜测"之上。

样本越大，这个猜测越准，bootstrap 越可靠。样本小的时候，它也会跟着不准——而且它自己不知道（给出的置信区间会显得比实际更窄，让你过度自信）。

它不能干什么（诚实边界）

它造不出样本里没有的信息 它不创造新信息，只是把已有信息重新排列组合。
  • 你的 5 天数据里没出现过暴跌 → bootstrap 也造不出暴跌
  • 你没有 2008 年的数据 → 它也给不了你"危机时会怎样"
  • 你只有 3 条规则 → 它变不出第 4 条
这个"不能无事生非"的特性，既限制了它的能力，也是它可信的原因。

在 5.7 里，它变了个小花样

标准 bootstrap 是"从样本里重抽样本点"。但 5.7 要检验的是"信号和市场之间有没有真实的对应关系"，所以它换了个更针对性的抽法：

固定规则，重抽市场 不重抽"样本点"，而是重抽"日子"——把市场收益率序列打乱重排，规则序列原封不动。

为什么？因为如果规则真有本事，它就应该能配上市场的节奏。把日子打乱，这个对应关系就被破坏了，规则自然赚不到钱。
"打乱后还能不能赚钱"，就是它有没有真本事最直接的检验。
同一件事的四种叫法 重抽样（resampling）——强调动作；平行世界——强调它造出来的是什么；"如果重来一次"——强调它在回答什么问题；bootstrap / 自助法 / 拔靴法——三个名字，同一个东西。
你的项目里其实已经在用它了，但用法不一样 你 E0/E1/E2 那套配对 bootstrap 置信区间（E1 的 [−0.006907, +0.003756]），就是标准 bootstrap：重抽日期，每次重算 RankIC 增量，抽 500 次得 500 个增量，取 2.5% 和 97.5% 分位点。

但你的代码里没有 (5.31) 那个减 f̄k 的动作。因为两件事不一样：
· 置信区间回答"这个数大概是多少" → 不减，直接看分布
· 假设检验回答"这个数是不是 0" → 必须减，把分布搬到原假设下

这正是你上次问"为什么 E2 区间窄就说'确定基本没有'"时，我一直强调的那个区别。

第 5 关公式 (5.31)：最难的一步，也是全节的灵魂

(5.31)
v*l,i  =  maxk=1..l  (  √n  ·  (  f̄*k,i  −  f̄k  )  )
第 i 次 bootstrap 重抽样得到的统计量。注意它减了一个 f̄k。
人话版（一句话）

「假设这 l 条规则其实全都没本事，那么在纯粹的运气作用下，最好的那条能撞出多好的成绩？把这个'运气上限'算出来。」

第一步：这里的 bootstrap 抽的是什么

前面插播讲过，bootstrap 的本质是"把样本当成整个世界，有放回地反复抽"。但 5.7 里抽的不是样本点，而是日子。

White 的办法是：把市场收益率序列反复打乱重排，而规则序列一动不动，造出很多个平行世界。

bootstrap 的关键：规则固定，市场打乱。红涨绿跌。
"规则原封不动"是什么意思？为什么规则不能动？ 图里上下两行地位完全不同：

· 规则 s 那一行，是已经发生的历史决定。"第 1 天做多、第 2 天做空……"这些不是随机量，是写死了的事实——你没有第二次机会"重新决定"，所以没东西可抽。
· 市场 r* 那一行，才是抽签抽的东西。平行世界问的是：如果市场这些日子换一串顺序来，这条规则会赚多少？规则当然不变——变的是它碰上的日子。

为什么不把规则也重抽？因为你检验的对象就是这条规则。把规则也改了，你测的就是另一台机器，跟原假设"这条规则没本事"毫无关系。

类比：查一个学生是不是蒙的。他的答案卷子是固定的（历史决定），你把标准答案的顺序打乱重新配对，再批一次分：
· 他真会 → 答案和知识点踩得准 → 乱配后分数暴跌（说明有真货）
· 他纯蒙 → 答案跟对错本来就没关系 → 乱配前后差不多（说不清）

你不会去改学生的答案——那就在考另一个人了。能动的是批分的配对方式，不能动的是考卷本身。

第一步补充：抽样单位是「日子」，必须整包走

你项目里的 paired_bootstrap 有个容易被忽略的细节，但它决定了整个检验成不成立。

每个交易日 t 是一个包，包里装着两个模型这一天的 RankIC：

包(t) = ｛ RankIC(E0, t), RankIC(E1, t) ｝

重抽时整包拿走——E0 和 E1 必须是同一个 t，绝不能把 E1 的第 3 天配给 E0 的第 6 天。

蓝框是被抽中的三个包，整包拿走；红框是拆开配对的反面例子。
拆开配对会怎样：造出一个虚假的巨大差值 假设第 3 天大盘大涨，E1 拿到 +0.043；第 6 天大盘平平，E0 拿到 0.033。
你拿 0.043 − 0.033 = +0.010 —— 看起来 E1 完胜。

但这个 +0.010 不是切割因子带来的，是"你挑了个好日子给 E1、挑了个差日子给 E0"制造出来的。

配对的唯一目的就是让两个模型经历同一天，把当天大盘这个共同因素消掉。一拆开，这个目的就作废了。
你的代码其实"自动"做到了这一点 evaluation.py 里是先做差、再重抽：
d = (b − a).dropna()　→　抽 idx　→　d[idx].mean()

因为 dt 本身就已经是"同一天两个模型之差"，差值把两者焊死了，所以"整包"不需要额外写什么——它自动成立。

如果反过来先抽 E0 的序列、再抽 E1 的序列、然后相减，就必须额外保证两次抽的是同一组日期、同样次数，非常容易写错。先做差再抽，是更简洁也更不容易出错的写法。
还有第二层"打包"：21 天一整段 你的 block = 21 意味着抽签抽的不是单个日子，而是连续 21 天的一整段，而且段内保持原来的先后顺序。

为什么要这么粗？因为相邻 20 天的标签共享 19/20 的信息，它们不是 21 个独立样本，更像 1 个样本。把它们整段搬走，才能把这种"黏在一起"的结构带进平行世界。

所以完整的说法是：抽样单位 = 21 天整段；段内顺序不变；段内每一天的两个模型成绩绑死。
"打乱交易日"和"选股不变"是怎么同时成立的？ 关键在于：选股行为早就发生了，它已经被"压缩"进包里那个数字了。

拆开一个包看：IC(E1, t3) = +0.043 这一个数，其实是三样东西焊在一起——
· 选股清单：第 2 天收盘时定好的持仓（历史事实，锁死）
· 当天市场：这批股票当天的涨跌（也是那天发生的事实）
· 两者相乘算出来的成绩

重抽时，抽中的包整包搬到新位置：平行世界的"第 1 天"可能原来是 t3——但 t3 包里的选股还是那次选股，涨跌还是那个涨跌，一个字都不会变。

所以两件事同时成立：变的是"哪些日子入场、按什么顺序入场"；不变的是"每个日子里的选股行为和当天的配对"。
两张图是同一原则的两个视角 插播那张图（规则固定、市场打乱）是概念示意：告诉你原假设是"信号和涨跌之间没有真实对应"。
这张图（整包重抽）是实现方式：因为每个包自带"当天的信号表现 + 当天的涨跌"，所以洗日子的顺序，就自动造成了"信号 ↔ 涨跌"的重新组合——不需要真的去洗市场。

类比：一沓考卷照片。每张照片里"学生的答案 + 批的分数"都印死在相纸上了（选股不变）；bootstrap 做的只是洗牌重排这沓照片的装订顺序（交易日打乱）。

一个诚实的小提醒：你的 paired_bootstrap 洗的是"哪些天入选、什么顺序"，不是把信号和涨跌强行重新配对——但因为包自带涨跌，两种写法在"破坏原有时序配对"这件事上效果等价。
这一步造出来的，就是「运气的基准线」 打乱后的成绩 = 没有真本事的信号能拿到的成绩。重复 B 次，你就有了 B 条运气基准线。

接下来要做的事，是让真实成绩去跟这 B 条基准线比。但为了比得公平，还差一步——就是 (5.31) 里那个减号。

第二步（最难）：为什么要减掉 f̄k？

这是整个公式里最容易被跳过、但最不能跳过的一个减号。慢下来讲。

先想一个问题 bootstrap 造出来的平行世界，是要模拟"这些规则其实都没本事"的世界。
那么在这个世界里，每条规则的真实水平应该是多少？
应该是 0。（"没本事" = 长期期望是 0 = 不比基准强）

现在看：如果你不减 f̄k，直接用 f̄*k,i 会怎样？

重抽样是从原样本里抽的，所以 f̄*k,i 的平均值，会围着 f̄k（原样本那个值）转，而不是围着 0 转。

不减的后果：检验完全失效 你的平行世界，中心不是 0，而是原来那个漂亮的成绩 f̄k。

那你拿真实值 vl 去跟这堆平行世界的值比，真实值自然就落在正中间——p 值永远在 0.5 附近，既不会显著，也不会不显著。

这就等于在说："我假设他真的有那么准，然后问他是真的准吗？"——循环论证，什么问题也回答不了。
强行把平行世界搬到"大家都没本事"的原假设下，然后才谈得上比较。
同一个减号，决定了这个检验是有用的还是废的。
一句话记住 减掉 f̄k，就是在平行世界里"没收"掉这条规则原本的成绩，逼它从零开始，看它光靠运气还能走多远。

第三步：p 值怎么算出来的

把上面的步骤连起来，一共四步：

1
算真实值 vl
用真实历史，按 (5.30) 算出 vl = maxk(√n · f̄k)。这是你要检验的那个数。
2
重抽样 B 次
每次都按 (5.31) 算一个 v*l,i。B 通常取 1000 或更多。得到 B 个"运气上限"。
3
把这 B 个数从大到小排成一排
这就是"如果全是运气，最好成绩能有多好"的分布。
4
看真实值 vl 插在这一排的哪个位置
p = （v*l,i ≥ vl 的次数）÷ B
如果 1000 次里只有 20 次超过了你的真实值，那 p = 0.02，可以拒绝原假设——最好那条规则确实不太像纯运气。
书上说的两个缺点，现在能看懂了 缺点一：检验偏保守。如果你往候选池里塞进一大堆很烂的规则，max 的那条仍然可能来自偶然，但临界值会被这些烂规则撑高，导致真有本事的规则也检不出来。
缺点二：只认第一名。整个统计量只回答"最好的那条真不真"，完全不告诉你第二名、第三名怎么样。这就是下一关 SPA 要解决的问题。

第 6 关公式 (5.32)：SPA，一次不只挑一个

(5.32)
SPAl  =  max (  0  ,  maxk=1..l (  √n  ·  f̄k  )  )
在最外层再套一个 max，跟 0 比。

你一定会问：这不就是 (5.30) 外面多套了一个 max(0, ·) 吗？对，就这点差别，但含义不小。

为什么要跟 0 比一下？ 如果所有 l 条规则全都比基准还烂，那么 maxk(√n·f̄k) 会是个负数。一个负数当"证据强度"用，会很别扭——你会陷入"越烂，统计量越负，好像越能说明什么"的荒谬境地。

套上 max(0, ·) 之后：只要全都烂，统计量就是 0，p 值直接等于 1，明明白白地"完全不显著"。这符合直觉，也让临界值好定。

真正的进步在"逐步"（stepwise）

书上的四个步骤，用淘汰赛来读特别清楚：

a
把 l 条规则按分数从高到低排队。
b
检验排第一的那条。如果它的 √n·f̄k 超过临界值 → 判它显著，踢出队列；没超过 → 全部结束，一条都不显著。
c
把被判显著的那条拿掉，用剩下的重新算临界值，再检验新的第一名。
d
重复 c，直到再也没有能被判显著的为止。
为什么每踢掉一个，就要重算临界值？ 因为"运气能撞出的最好成绩"取决于候选池有多大。

类比：100 个人每人抛 10 次硬币，"有人抛出 8 次正面"一点都不稀奇；但如果你已经把抛得最好的那个人剔掉了，剩下 99 个人里再出现 8 次正面，就没那么容易了。候选变少，运气的天花板就跟着降低，门槛必须收紧。

如果不重算、一直用第一轮那个最宽松的门槛，第二轮就会把关不严，把一堆运气好的误判成真本事。
FWE：这类检验用的是"家族错误率" 书上特别点出：(5.29) 是个联合假设（同时管着 l 条规则），所以要用 FWE（Family Wise Error Rate） 来评判。

FWE 的定义："至少错误地判显著了一条其实没本事的规则"的概率。控制 FWE = 保证"一个假阳性都不要有"。

代价是非常保守，容易漏掉真东西。这就是后面 Bajgrowicz 与 Scaillet 改用 FDR（容忍一定比例的假阳性，换取更大检出面）的动机。

最容易记错的三件事

  1. 星号 = 假数据，不是乘号。f* 是 bootstrap 造出来的，不是历史。
  2. (5.31) 那个减号不能省。省了检验就废了，p 值永远 0.5。
  3. max 是在 l 条规则上取的，不是在时间上取的。它问的是"这堆里最好的那个"，这就是多重检验。

回到这跟你项目什么关系

  • E0 / E1 / E2 横向一比，就是 (5.29) 里的那个 max。你现在只有 3 个候选，l = 3；书上 Sullivan 他们用了 l = 7846。数量差很多，但性质一模一样。
  • 你现在的配对 bootstrap 置信区间，等价于只做了"单条"检验。要给三个模型做联合判断，需要的是这里的 vl 与 v*l,i 这套东西。
  • (5.28) 里"s 只能用 t 时刻之前的信息"这条底线，就是你的 available_at 与 published_at 之分。同一条规则，两种写法，一个合规一个前视。
  • √n 提醒你一件事：E1 那个 RankIC 增量 −0.001297，是在多少个样本日上算出来的？样本日一多，同样大小的增量含金量完全不同。你报置信区间的时候，最好把 n 一起报出来。
