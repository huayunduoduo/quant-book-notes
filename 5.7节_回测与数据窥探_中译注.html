回测与数据窥探
样本内与样本外绩效评估

原书 5.7 Back-Testing and Data Snooping: In-Sample and Out-of-Sample Performance Evaluation · pp.171–173

这一节回答一个让人不舒服的问题：你在同一份数据上试了一百个规则，挑出最漂亮的那个——它到底是真有用，还是只是运气最好的那个？

为什么要读这一节 你项目里 E0 / E1 / E2 三个模型在同一批数据上比较，本质上就是多重检验。而你手册里那句"仍需考虑研究选择和多重比较"，指的就是这一节讲的东西。书里给的正是治这个问题的标准工具。

第一段技术规则曾"证明有效"，然后被证伪

p.171

随着 Brock、Lakonishok 与 LeBaron（1992）那篇关于技术规则的论文发表，主流金融学界开始认真研究这类规则的性质。所考察的规则，大多是移动均线和交易区间突破的变体。

把这些规则用在 1897 至 1986 年的道琼斯指数上，结果显示技术策略表现良好，且结果与常见的基准模型都不一致——包括随机游走、AR(1)、GARCH-M 和指数 GARCH。此外买入信号普遍比卖出信号表现更好。这些规则的 p 值是通过 bootstrap 方法估计的。

但 Ready（2002）指出：Brock 等人的移动均线规则在扣除交易成本后看起来仍然成功，其实是数据窥探造成的假象。规则在 1986 年之后表现很差，而且 1987–2000 年间，策略建议"空仓"的那些日子，平均收益反而更高。因此技术规则的绩效必须被审慎评估。

注解 · 这一段的杀伤力在最后一句：策略让你别买的时候，市场涨得更多。这不是"策略失效"，这是"策略一直是反的"——典型的过拟合症状。注意时间切分：1897–1986 是样本内，1987–2000 是样本外，表现直接崩掉。

第二段数据窥探的根源与幸存者偏差

p.171–172

数据窥探（data snooping）指的是：同一份数据既用来选模型，又用来验证模型。这样得到的显著性结果，可能纯粹来自运气。正如 Sullivan、Timmermann 与 White（1999）所指出的，数据窥探还可能来自幸存者偏差——因为只有成功的规则才会被拿去复现。

因此，要研究窥探偏差，必须把几乎全部的规则宇宙都纳入考察，只挑少数几个是看不出问题的。

注解 · 这是全节最该抄下来的一句："同一份数据既用来选模型又用来验证模型"就是数据窥探的定义。你项目里"滚动前进、每年重新训练、只用样本外年份评价"，正是为了躲开这个陷阱。别忘了：你在 2017–2020 上反复调参，那段时间就已经从样本外退化成样本内了。

第三段White 的 Reality Check（真实检验）

p.172

建议采用 White（1999）研究的 bootstrap 程序来检验数据窥探偏差。偏差主要来自在同一批数据上套用大量交易规则，于是纯凭运气也能撞出一些显著结果。

设有 l 个待考察的交易规则，在随后的 n 个时期上验证，定义：

(5.27) f̄ = (1/n) · Σj=1..n f̂t+j f̂t+j = 第 t+j 期观察到的绩效度量，仅基于截至 t 的数据算得
(5.28) fk,t+j = ln(1 + rt+j · sk) − ln(1 + rt+j · s0) rt+j = 收益率；sk 与 s0 = 第 k 个规则与基准规则的信号函数

基准（benchmark）规则可以取三种仓位：做多、做空、空仓，分别取值 1、−1、0。信号函数当然只能基于截至 t 时刻可得的数据与信息。

检验的原假设是：最好的那条技术规则，并不比基准规则更好——

(5.29) H0 : maxk=1..l E[fk] ≤ f0 拒绝 H₀ 才能确立"最优技术规则确实优于基准"。同样的假设也可以对夏普比率（风险调整后收益）来提。

H₀ 的 p 值通过 bootstrap 重抽样获得。设由重抽样得到 B 个 fk 的值，记为 f*k,i（i = 1,2,…,B），构造统计量：

(5.30) vl = maxk=1..l (√n · f̄k)
(5.31) v*l,i = maxk=1..l (√n · (f̄*k,i − f̄k)) 把真实的 vl 与重抽样得到的 v*l,i 分布比较，就得到 p 值。

Sullivan 等人（1999）考察了 l = 7846 条交易规则，覆盖得相当彻底；基准规则设为"始终空仓"。

两种方法得到的 p 值——bootstrap 重抽样法与传统名义法——在样本外时期上差异相当大。不过，确实仍有少数规则在平均收益和夏普比率两方面都跑赢了基准。

上述检验有两个主要缺点：其一，检验偏保守，当规则宇宙里塞进大量表现很差的模型时，检验功效会下降；其二，除了"表现最好的那一个"，它无法识别出其他显著的模型。

注解 · 注意 (5.30)(5.31) 在比什么：不是在比"某个规则好不好"，而是在比"所有规则里最好的那个，能不能好到不像是运气"。这正是多重检验的核心——你把 7846 个里挑最好的，当然一定好看；问题是它比"运气能产生的最好结果"好多少。

第四段逐步 SPA 检验：一次不只挑一个

p.173

Hsu、Hsu 与 Kuan（2010）对 Hansen（2005）提出的优越预测能力检验（Superior Predictive Ability, SPA）做了逐步化（stepwise）改进，并采纳了 Romano 与 Wolf（2005）的修正方案。检验统计量为：

(5.32) SPAl = max( 0 , maxk=1..l (√n · f̄k) ) 临界值由重抽样决定

具体步骤如下：

  1. (a) 把 fk 按从大到小排序。
  2. (b) 若最优模型 k 的 √n·f̄k 大于临界值，则拒绝它；若没有模型被拒绝，则停止；否则进入下一步。
  3. (c) 剔除已被拒绝模型的 fk，重新生成临界值。再做检验；若没有模型被拒绝则结束，否则进入下一步。
  4. (d) 重复 (c)，直到再没有模型能被拒绝为止。

(5.29) 中的假设是联合假设，因此这类检验要用 族错误率（Family Wise Error Rate, FWE）来评判——即"至少错误拒绝了一个正确的原假设"的概率。

Hsu 等人考察了滤波规则和移动均线规则两类技术规则，用在多个市场指数和 ETF 上。确实有若干规则带来了平均收益的显著提升，夏普比率也表现不俗。

注解 · SPA 相比 White 的进步在逐步剔除：White 只回答"最好的那个真不真"，SPA 能一轮一轮往下筛，给出一串显著模型。而每剔除一个就重算临界值，是因为"剩余候选变少了，运气能造成的最好成绩也随之下降"——临界值必须跟着收紧。

第五段FDR 视角：技术规则最终被判了死刑

p.173

Bajgrowicz 与 Scaillet（2012）采用错误发现率（False Discovery Rate, FDR）的概念，得出了与 Ready（2002）一致的负面结论。FDR 在共同基金绩效领域由 Barras、Scaillet 与 Wermers（2010）做了详细研究。

上面最后讨论的那种方法，只能告诉你"某条规则在扣除了数据窥探之后是否跑赢基准"，却给不出关于其他策略的任何信息。但现实中，投资者是同时参考多条规则的信号，而这些规则在概念上和经验上都不是相互独立的。

FDR 方法通过容忍一定数量的错误发现，既考虑了规则之间的依赖性，又能提供一组高绩效规则（而不是只给一个）。

Bajgrowicz 与 Scaillet 还处理了这些规则的持续性问题，为每一个交易信号配上了贴近现实的交易成本。

他们基于道琼斯工业指数 1897–1996 年的日频数据，主要发现是：

原书引述 "我们无法选出这样一些规则：它们的表现既能持续，又不被交易成本抵消。"

他们的结论是："……投资者应当对任何一个投资网站上都能看到的那些常见技术指标保持警惕……"

不过他们也承认："……我们的结果对于其他市场、其他频率或更精密的规则下是否存在盈利策略，说不上什么。"

——而这些警告，似乎并没有妨碍技术规则在实务中被继续使用。

三个方法一图看懂

White (1999)
Reality Check		 只问：最好的那一个真不真 保守；塞进一堆烂模型会损失功效；只认第一名
Hansen (2005)
Hsu et al. (2010) SPA		 逐个往下筛，每剔除一个重算临界值 能给出一串显著模型；用 FWE 控制"至少错杀一个"的概率
Bajgrowicz & Scaillet (2012)
FDR		 容忍一定比例的假阳性，换取更大检出面 能处理规则之间的相关性；结论最负面
FWE 和 FDR 的区别，一句话讲清 · FWE：我要保证"一个假阳性都不要有"。代价是极其保守，容易漏掉真东西。
· FDR：我允许发现里头有 5% 是假的，但剩下的 95% 得是真的。检出面大得多。

类比：FWE 像"宁可错放一百，不可错抓一个"；FDR 像"抓一百个人，我能接受里面混进五个无辜的"。

这一节对你项目的四个直接启示

  1. 你已经在做"样本外"，但还在做"多重比较"。滚动前进解决了"同一份数据既选又验"的问题；但 E0/E1/E2（以及可能的 E3/E4）横向一比，就产生多重检验问题。书里这三个方法正是为此设计的。
  2. 你手册里那句"仍需考虑研究选择和多重比较"，出处就在这里。你现在有配对 bootstrap 的置信区间，但那是针对单个增量的；如果同时检验多个因子、多个变体，需要的是 White/SPA/FDR 这类联合检验。
  3. "最漂亮的那个"最该被怀疑。书里 7846 条规则里挑最好的，名义 p 值和 bootstrap p 值差得很远。你项目里如果试过多种子、多参数、多特征组合，然后只报最好的一组——那就是数据窥探。
  4. 成本是最后的照妖镜。Bajgrowicz 与 Scaillet 的关键一步是"给每个信号配上现实交易成本"，结论立刻反转。你的费用后 CAGR 一定要和 RankIC 一起报——这正是书里反复强调的做法。
